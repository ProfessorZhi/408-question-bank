# 2009–2025 408 综合题“相对前作”原创性纵向审查

> **2026-10-20 · 主体：2009–2025 年真题共 17 卷、119 道综合题。** 逐题读取仓库 main 的 `papers/exams/<year>/questions.md`。这是围绕“后一年相对所有更早 408 年份”的编辑分析，**不是**题目著作权独创性的法律判定，也不宣称其中算法为当年才被发明。部分历史 Markdown 存在 OCR / 公式 / 图表未独立 PDF 校核的问题，因此判断仅达到“题干研究”而非官方命题报告或考生心理测量。

## 一、何谓真正有意义的“题目新意”

- **I · 推理机制创新**：前作主要要求执行算法，新作却要求证明唯一性、构造反例、诊断错误实现、反推条件、处理边界等；具体知识可完全是旧知识。
- **II · 条件改变解法**：限制时间/空间、动态事件、初始状态、可用资源、协议回绕或硬件路径等，**使最优思路与状态转移真的不同**。
- **III · 跨域因果融合**：上一问算得的结果、同一真实数据路径或系统行为构成下一问不可跳过的建模输入。仅把IP、ARP、TCP写在同一张拓扑中，不满足这一标准。
- **IV · 情境包装**：卫星、航天、公司网络、植树、银行、校园等作为可读背景；只有实际参数（长传播距离、共享工具、带宽时延积等）**改变推理机制**时才计入创新。
- **V · 经典题型延续**：常见的PV同步、查找、页表、磁盘、Cache、子网等换数值或改应用名称；**依然可能是优质真题**，但相对新增机制低。

下述年度等级分为 **突出（同年出现多项有意义新机制）、较强（至少有几项真实进阶）、稳健（局部有亮点、经典延续为主）**；2009 年是基准年，无法“与此前的408年度”比较。评价不是题目难度、质量或独创权重的同义词。

## 二、每年相对所有前作的创新

| 年份 | 综合原创性评价 | 相对前作较新颖的题型 / 核心转折 | 典型经典延续或限制 |
|---|---|---|---|
| **2009** | **基线** | Q41 不接受贪心最短路径“看似正确”，要求反例；Q42 单链表倒数第k的算法设计；Q44 数据通路控制节拍；Q45 奇偶分类生产消费；Q46 TLB/缺页复合状态 | 这是统考系列的起点，不能把此前没有408样本造成的“首见”视为年度创新 |
| **2010** | **较强** | Q42 原地数组循环左移的时间/空间双优；Q44 同功能程序不同数组访问方向导致Cache差异；Q45 从磁盘调度扩展到SSD介质性质；Q47 CSMA/CD碰撞传播时序 | Q41散列表过程与Q46页置换延续经典硬计算 |
| **2011** | **较强** | Q42 两个等长有序序列的中位数，需要缩小问题规模而非合并；Q44 TLB—页表—Cache联动；Q47 数据帧十六进制+ARP/HTTP跨层提取信息 | Q45银行服务窗口信号量仍是有界缓冲经典变体 |
| **2012** | **较强** | Q41 把有序表最小比较代价合并建模为最优合并；Q42 尾部共享链表的公共后缀；Q45 具有回收链与再命中复用的页面策略；Q47 用抓包表推断TCP/以太网状态 | Q43访存率/带宽与Q46块索引仍偏传统核算 |
| **2013** | **较强** | Q41 主元素判定从直接计数升级为线性多数候选+复核；Q42 不同存储实现下按访问概率选择查找组织；Q44 为定制分支指令设计标志位条件 | Q45博物馆出入口信号量、Q46多级页表、Q47路由聚合的基本原理更接近已有套路 |
| **2014** | **突出** | **Q42→Q43**：OSPF链路状态信息→图/链式表示→最短路径→路由表/TTL，在同一真实拓扑中跨 DS×CN；**Q44→Q45**：同一程序的机器码→Cache/页式访问，形成共享执行情境 | Q41 WPL是树递归典型变体；Q47仍是生产者/消费者PV并增加连续取出约束 |
| **2015** | **较强** | Q41 在有界绝对值域下做链表去重，空间优化有因果作用；Q42 从邻接矩阵的幂解释路径数量；Q43→Q44 同一CPU数据通路、指令格式与控制微操作 | Q45两信箱PV及Q46页表计算、Q47 DHCP访问以既有知识为主 |
| **2016** | **较强** | **Q41** TCP接收缓存只进不出，使流控窗口归零，须与拥塞窗口/序号一起推演；Q43 优化整数集合划分的目标函数；Q46 由CPU等待/运行时间动态修正优先数 | Q45 TLB/Cache/页式访存以及Q47 FAT/目录偏经典结构模拟。**注意当年Q41才是网络综合题，Q47为文件系统** |
| **2017** | **突出** | Q41 表达式树输出中缀表达式，要考虑括号与运算语义；**Q43→Q44→Q45**：同一C函数的整数/浮点解释→机器代码→OS地址/中断机制；Q47 双向GBN捎带确认、超时与窗口时序 | Q42 MST唯一性是在经典图算法上更深入，但并非新算法 |
| **2018** | **较强** | Q41 最小缺失正整数及边界空间权衡；Q42 MST最小铺设成本与IP TTL的真实路径联系；**Q44→Q45** Cache/TLB/页目录及进程/线程切换同一机器背景；Q47 分片长度/偏移受MTU约束 | Q43查询/中断/DMA开销与2009、2016命题路线重合；Q46多级索引块计数相对传统 |
| **2019** | **突出（DS较突出）** | Q41 单链表原地首尾交错重排；**Q42** 特制队列要求空间只增不减、出队复用和入/出队恒O(1)，题目迫使重新选择结构；Q43 哲学家在筷子以外增加有限碗；Q45→Q46 函数机器码延伸至指令Cache | Q47路由器/交换机及NAT设备配置较常规；Q45→Q46的共享机器做法已在2017等年份出现 |
| **2020** | **稳健，有独立亮点** | Q41 三个已排序集合最小距离的多指针联合优化；Q43 乘法函数、ALU/移位实现与阵列乘法器的硬件/软件选择 | Q42 前缀码树、Q44 Cache、Q45操作先后PV、Q46二级页表、Q47 NAT状态较多沿用早先路线 |
| **2021** | **突出** | Q41 以欧拉路径必要充分条件写成图算法；Q42 不仅运行排序代码，还需判断并修复稳定性；Q45 审核使用关中断实现信号量的**错误方案**；Q46 上电/多级引导；**Q47** DNS—ARP—交换机学习的同一次HTTP请求状态推演 | Q44 TLB组映射仍是旧知识的参数变化 |
| **2022** | **稳健，有情境创新** | Q41 用带-1缺失标记的顺序二叉树验证BST性质；Q42 在n很大、k=10约束下选算法；Q47 将AP/Hub/交换机、冲突域、DHCP与802.11帧地址放入网络架构判断 | Q43数据通路、Q44磁盘/DMA、Q45文件索引、Q46信号量依旧是标准机制；多项题组合并未都引入新推理 |
| **2023** | **较强** | Q42 外排序置换—选择生成归并段；**Q43→Q44** 二维数组的虚存/Cache访问与同段机器指令串联；Q45 swap互斥实现的调错和原子性；Q46 键盘系统调用阻塞→中断→唤醒事件重建 | Q41 比较入出度的代码较直接；Q47 FTP传输、TCP拥塞/序号组合既有机制但场景推理完整 |
| **2024** | **突出** | Q41 从普通拓扑排序转向**判定拓扑序列唯一性**；**Q43→Q44** 以同一ISA/数据通路连接机器指令、内存与C数组语义；Q45 研究页表所在页的地址及自指访问；**Q47** RIP收敛时序+OSPF选择+eBGP/iBGP通告和下一跳 | Q42散列表二次探测、Q46信号量协作均不算崭新机制 |
| **2025** | **较强** | Q41 将数组后缀极值与乘积正负号联动；Q42 从静态AOE关键路径升级到活动延迟和压缩的**动态反事实**；Q43→Q44 Cache/机器除法器/异常响应交叉；Q46 C变量与进程内存布局、设备服务界限 | Q45 三阶段植树+共用铁锹属于经典PV问题的强化版；Q47 卫星距离→RTT→GBN窗口很有约束价值，但最后IPv4子网问相对独立，整题不全是因果闭环 |

## 三、网络综合题的单独演化：为什么新的Q47应该提高标准

**不能假设所有年份的 Q47 都是计算机网络：2014 年的网络综合题是 Q42/Q43，2016 年是 Q41。**

| 年份 | 网络大题与真正的任务转折 | 相对过去的增量 |
|---|---|---|
| 2009 | Q47 IP子网、路由表与聚合 | 基准 |
| 2010 | Q47 CSMA/CD碰撞传播、停等确认与有效速率 | 加入物理时延与链路吞吐机制 |
| 2011 | Q47 Ethernet帧十六进制→ARP→HTTP | 把抓包原始字节转换为分层语义 |
| 2012 | Q47 TCP/IP报文捕获记录→字节数与连接状态 | 从协议定义提升为观测记录反推 |
| 2013 | Q47 路由聚合及跨自治系统接口判断 | 在同一转发模型中考虑不同路由层次 |
| 2014 | **Q42–Q43** OSPF链路状态→图算法→路由表 | 强跨学科、跨题因果链 |
| 2015 | Q47 DHCP地址分配与Web访问 | 端到端服务配置与协议应用 |
| 2016 | **Q41** TCP接收缓冲不消费→通告窗口收缩、最终归零 | 有效动态条件改变传输过程 |
| 2017 | Q47 双向GBN捎带确认与超时重传 | 同一时序图中窗口/确认/重传强联动 |
| 2018 | Q47 跨MTU的IPv4分片；Q42 MST布局关联TTL | 分片数量、字节偏移和路径长度的实际约束 |
| 2019 | Q47 设备选型、接口地址和NAT | 有工程配置意味，但核心逻辑较常规 |
| 2020 | Q47 NAT路径上逐跳地址变化 | 有状态转发理解，但与旧年明显同族 |
| 2021 | Q47 DNS→ARP→MAC自学习→HTTP请求 | 利用初始空表与时间窗口反推必然发生的事件 |
| 2022 | Q47 AP、集线器和交换机选型→冲突域/802.11地址/DHCP | 网络设备语义混合，适度新意 |
| 2023 | Q47 FTP数据连接→TCP序号/cwnd→发送时间 | 同一次上传行为串联应用与传输 |
| 2024 | Q47 RIP收敛、RIP/OSPF适配、BGP会话与下一跳 | 路由协议的尺度、收敛与域间机制同时考核 |
| 2025 | Q47 卫星传播时延→GBN窗口/序号位数；另有子网规划 | 前半具有物理约束驱动的推理升级，末问独立度较高 |

**结论：** 网络综合题的强创新通常来自 **时序、状态、资源约束、观察数据的逆向推断、协议适用性**。不应将“ARP+TCP+CIDR”同时出现简单认定为原创。

## 四、反向审查 Set 01 七道综合题

| 题号 | 当前版本方向 | 相对历史题目的主要原创性问题 | 初步处理 |
|---|---|---|---|
| **Q41** | 两条有序链表求共同连续版本段 | 仍类似“链表交集/双指针+最长连续段”，问题更复杂不等于思路更新；2012公共后缀、2019重排等旧题已占据链表算法机制 | **需重构推理目标**，不是仅替换故事 |
| **Q42** | AVL插入/前驱删除/ASL | 早期已有AVL调整、BST查找和ASL；直接重复操作模拟属于传统题型 | **应引入可证的性质判断或不可行条件**，控制在10分 |
| **Q43** | 5段流水线前递与分支 | 流水线冒险/冲刷已有历史源，且当前Q19选择题同族 | 保留机器背景但要避免与本卷其他题同质 |
| **Q44** | 与Q43共享ISA的编码/小端/程序含义 | 2014、2015、2017、2024多次出现共享机器背景；共享设定并不自动有创新 | 让Q44必须利用前题结论或真正新的数据通路限制，而非平行计算 |
| **Q45** | 采集/校验/归档三阶段、两槽缓冲、共享设备 | **与2025 Q45“植树三阶段+共用铁锹+容量限制”非常接近**；当前故事换成传感器，不够新 | **优先淘汰原方向并重设机制** |
| **Q46** | read/DMA→阻塞→中断→唤醒 | **与2023 Q46的键盘系统调用→中断→唤醒事件顺序属于同一个机制族**；虽然DMA有变化，仍主要是事件排序 | 改成系统机制的**错误诊断、反事实或必要条件判断** |
| **Q47** | 子网、ARP、TCP字节序号、rwnd吞吐 | 2009/2011/2015/2021/2023/2025的考查点简单相加，四问可以分别独立求解；图的IP和MAC没有造成新推理转折 | **直接退回重命题，而不是改IP、加设备或加计算量** |

这里判断的是**相对历年408命题方式的创新程度**，不是断言这些题没有训练价值。当前Q47数值计算已有作者交叉验证，但**计算正确与命题创新不足可以同时成立**。

## 五、下一版必须采用的原创性闸门

1. **相似题检索基准**：与旧题比较不止“章节相同”，而是记录 `已知量→状态变化→唯一关键推断→得分点` 的逻辑骨架。
2. **因果链检测**：删除背景中的某条件、替换某协议状态或改变某资源限制，如果正确答案与解法几乎不受影响，这个条件很可能只是装饰。
3. **反事实/逆向能力**：允许考察在约束改变时系统能否成立、哪个推断不再成立、为什么某看似合理算法是错的，但不能无故变成竞赛题。
4. **历史强项学习**：优先研究2014的OSPF跨科联动、2017共享程序/机器码/分页、2021协议事件反推、2024拓扑唯一性与域间路由机制、2025 AO​​E动态扰动。
5. **打分方式**：学术正确、考纲覆盖、难度控制与原创性分别计分；只要属于“旧题换背景”，无论其他维度多好，**不评为10/10原创命题**。
6. **不强求每题创新**：真题一直保留大量经典题。允许卷内1～3个扎实经典综合模块，真正高原创性的题集中在2～4道，但不能七题都沦为换皮模板。
7. **不自动修改题面**：先将本历史审查结果作为研究依据，待新的问题机制通过独立概念审稿，再替换现有Q41–Q47，保持学生卷不泄漏答案。

本次只评价及记录研究，未作2024/2025试题版权复制，也不把“原创性等级”伪装成有样本的区分度指标。
