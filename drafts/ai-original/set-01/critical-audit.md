# Set 01 · 首轮作者对抗式检查

## 方向淘汰与成稿修订

原Q41最短删子数组方案与公开常见练习过近，已在方向阶段淘汰；当前改为两条只读链表求公共连续整数段，要求重复值去重、平局规则和常量辅助空间。旧Q05的BFS/DFS组合亦撤回，改为删除非树边的距离不变量。

正式成稿进一步规定了所有易产生多解的模型前提：NIL、B+树扫描策略、KMP下标、CF借位、浮点单次舍入、C类型提升、结构体padding、流水线边界、LRU初态、C-SCAN回卷、交换机不产生ARP、TCP缓存采样时点和教学分轮窗口。

Q32区分固件与内核启动依赖。**历史v1的Q46**曾是DMA/中断/进程唤醒题，已在v3整体撤回；**当前Q46**改为COW写保护异常、物理页引用计数与退出后的权限状态推理。Q41明确输出指针不与输入结点重叠，避免正确算法通过别名意外改变输入。

## 程序反证能力

旧Q45验证器曾通过交换 P(empty) 与 P(dev) 检查死锁；该测试已随题目重写而废止。当前Q45模型检查指定订阅者身份、重复消费、槽位覆盖、并行读取和死锁。Q41使用集合排序基准而非把同一双指针算法复制成Python作为唯一标准。

## 2026-10-20 · 历年原创性专项复审（v1问题记录，已由v2重命题处理）

另见 [2009–2025历年119道综合题原创性纵向审查](originality-evolution-2009-2025.md)。**此段保留v1阶段的创新不足判断，用于追溯退题理由；v3现行题目需依新题机制单独评价。任何版本均不应仅凭47/47及程序验算宣称10/10。**

- **v1 Q45问题（已处理）**：三阶段共享设备模板与2025 Q45过近。v2改成单槽数据必须分别交付两个指定订阅者，并让考生构造共享ready许可被同一订阅者重复消费的调度反例。
- **v1 Q47问题（已处理）**：子网/ARP/TCP/吞吐拼盘缺少因果闭环。v2改成不完整分片抓包逆推：同一数据报的末片确定总长，首片长度把未知MTU约束到一个区间，IP重组完整性又决定何时TCP累计ACK可以前进。
- **Q42与Q46中高优先级**：AVL插删和DMA读阻塞→中断→唤醒已经有多年前的直接近似机制（例如2023 Q46键盘IO事件顺序），现题增强条件不等于新命题。
- Q41、Q43–44亦需检查是否只是“有序双指针求交”或旧款共享教学处理器的重复组合；必要时重构任务目标，而非继续堆细节。
- v2题面、解析、结构化spec、SVG和程序检查已同步；详见 revision-20261020-focus.md。其机制差异仍需独立命题审稿，不宣称已通过全网原创性验证。

## 尚须独立质疑的地方

- 图题与纯数值题虽有数据校验，图的语义和布局仍需另一人核对。
- 部分概念题可能偏基础，Q7/Q13/流水线题可能偏细；180分钟负担未实测。
- 大题多约定保证公平性，也可能增加阅读负担；共享CPU设定需评估文字压缩而不损失严谨。
- 通用知识点自然与教材练习重叠，本卷未通过全网查重或原创唯一性证明。
- 有限穷举不能替代一般数学证明；作者的测试模型也可能共享出题误设，不能因此自称独立双审。

当前交付是完整且可检查的试卷初稿，不是已获10/10认证的考试产品。


## 当前 v3 创新复审：此前指出的Q46/Q47缺陷已按新题型重新处理

- **v1 Q46**（DMA/输入/中断事件）因与2023年Q46机制近似被整题撤回；**当前v3 Q46**为父子进程COW权限/引用计数及异常与复制的条件性区别，不再要求排序六个DMA事件。新题仍须独立确认考试范围适配：所有COW规则已完整给出，不能默认考生知道特定内核。
- **v2 Q47**（不完整IPv4分片抓包）也被整题撤回；**当前v3 Q47**由链路费用改变+各路由器异步更新下一跳，引出仅R2更新时的暂态二节点环与TTL丢弃，再证明唯一无环逐台更新顺序。不存在IP分片、MTU和TCP序号计算。
- **Q45 v2维持不变**，其错误通知逻辑与Q46物理页保护、Q47路由更新互不重复。
- Q41/Q42/Q43/Q44仍以常规高质量综合题承担46分，不宣称“全卷每道大题历史首见”，但对题目清楚、考纲、严谨和实际耗时保持高标准。
