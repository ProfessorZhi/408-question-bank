# Set 01 · 独立盲审交接与审查记录模板

> 状态：**待外部审稿人执行，尚无第二位独立命题人签核**。本文件只规定交接与取证方法，不含正确选项、具体数值答案、评分参考解、已知错误的解题提示或“已经通过”的暗示。

## 盲审材料与隔离

1. 第一阶段仅向审稿人提供 [学生卷 questions.md](questions.md) 及其引用的14张学生题图。**不得预先阅读** [教师解析 solutions.md](solutions.md)、[结构化规格 specs/exam.json](specs/exam.json)、[校验脚本 verify_paper.py](verify_paper.py)、公开相似性扫描或其他包含预期结论的资料。
2. 请审稿人独立完成40道选择题与Q41–Q47的推导，记录每道题的候选答案、关键步骤、用时、歧义、是否使用了题面以外的隐含前提。若可能存在第二个正确选项，写出另一种**与题面兼容**的解释或具体反例。
3. **锁定独立作答记录后**才开放教师卷与结构化规格，对照作答结果及各小问给分。仍允许反对参考答案；分歧必须按数学、程序语义或定义作出裁决，不可默认出题者正确。
4. 最后进行原创性审查、图片A4灰度打印及手机缩放阅读审查。原创性核查至少比较条件、关键状态、推理顺序和评分点，**不能只比故事背景与数值**。

## 必须覆盖的核对维度

| 范围 | 盲答后重点核对的风险 | 记录要求 |
|---|---|---|
| Q01–Q11 数据结构单选 | 最坏情况、边界输入、并列决策、图树不变量、选项唯一性 | 每题答案及一条排除其余选项的理由；歧义附反例 |
| Q12–Q22 组成原理单选 | 位宽和类型提升、溢出标志、舍入、访存状态、微指令编码、单位/时序 | 标注依赖题外实现规则或缺少初态的地方 |
| Q23–Q32 操作系统单选 | 中断/系统调用、文件偏移和生命周期、调度与页面替换 | 对纯概念题检查术语的适用范围与反例 |
| Q33–Q40 网络单选 | 链路传输与排队、协议层含义、窗口回绕、TCP累计ACK、连接时序 | 写出模型前提与关键事件次序 |
| Q41–Q42 数据结构综合 | 空输入、重复值、边界、最优性/复杂度证明、树操作唯一性、给分 | 独立算法或手工推导；指出是否允许等价方法 |
| Q43–Q44 组成原理综合 | 周期级边界与冒险；指令编码和端序；两题间隐含依赖 | 完整独立时序与字节/字段计算，核对连锁失分 |
| Q45–Q46 操作系统综合 | 合法并发交错、活性/安全性、页框与权限状态变化 | 写出反例或关键状态表，标明条件是否足够 |
| Q47 网络综合 | 稳态最短路、混合转发表、TTL、更新顺序必要性 | 独立逐跳轨迹及其他更新序列的反例 |

## 一道题的审查记录（逐题复制使用）

```text
题号：Q__
独立作答/推导：（选择题填写所选字母；综合题填写每问结果和主要步骤）
实际用时：__ 分钟
是否有多个合理答案：否 / 是（若是，写出第二解释或反例）
题干是否缺少必要约定：否 / 是（写出可能的不同答案）
图表/版式问题：无 / 有（标明图号、位置、缩放条件）
对照教师解答后：一致 / 出题者解答可能有误 / 仍无法裁定
评分细则：可按等价正确方法给分 / 存在误伤（说明）
新意判定：经典题 / 新组合有推理增量 / 与已知题高度同构（附出处）
严重级别：P0必须修复 / P1应修复 / P2排版文字 / 无问题
证据或复现步骤：
审稿人及日期：
```

## 结论门禁与交付

- **P0**：题意有第二合理答案、数值/程序语义错误、图文矛盾、关键隐含前提、评分无法按正确方法给分；应停止定稿，修复后由审稿人重新核验受影响题目。
- **P1**：高度同构、阅读成本显著超预算、选项干扰失效或正当解法被过度限定；提出最小改题方案并保留理由。
- **P2**：排版、标题、符号一致性、图片缩放/灰度效果等。

审稿人需要提交：40道选择题的独立答案、7道综合题的独立解答、逐题疑点与P0/P1/P2记录，以及总卷180分钟试做是否完成的**实际事实**（不能将编辑预估当成实测）。任何一项缺失都应在验收说明中标记“未覆盖”，不得填写“全部通过”。

**重要**：作者的42/47等数字、CI绿色及第二套作者编写的程序模型都不代表上述盲审已经发生；使用本模板本身也不构成盲审。
