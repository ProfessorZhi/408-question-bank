# Set 01 · 已执行的验证与边界

本报告描述**出题者运行的程序交叉检查**，不标成另一位Agent/专家的独立签核。精确运行结果由 `verify_paper.py --json PATH` 生成；GitHub Actions会保存该JSON为构建产物。

## 1. 全卷结构

47个连续题号，40题各4个不重复选项，47份对应解析，综合题分值13/10/12/11/7/8/9合计70，连同80分单选共150分。学生卷未包含答案表或答案字段，13张学生图与1张教师图分离。Q41解答内的C代码与实际编译源文件进行文本比对。

## 2. 三种不同验证状态

| 状态 | 范围 | 实际含义 |
|---|---|---|
| computational-cross-check | 40题（除下两行） | 用可执行计算、结构枚举或模拟复核至少一个主要数值/结构结论，并检查所选答案；不能自动证明所有自然语言选项的全部语义 |
| editorial-only | Q20、22、23、24、29、32 | 基于题定模型、术语和标准语义的作者解释；不把人工写入布尔真值表冒充独立程序证明 |
| constraint-only | Q46 | 验证已规定的事件次序与结构完整；中断现场、模式及系统语义仍需编辑审查 |

所有47题均为 **drafted / independent_review=false / pilot_calibrated=false**。结果可复算，不等于已获得终审。

## 3. 重点可执行证据

- **Q1**：枚举小数组，核查j单调且总增量不超过n；一般性线性上界由解析计数证明。
- **Q2–Q4**：枚举容量受限栈序列、全部5结点二叉树形、哈夫曼平局选择；核验唯一可选项、4棵匹配树以及WPL/最大码长。
- **Q5**：枚举2–5顶点的连通无向简单图、多源BFS及非树边删除，共6263个删除检查；源距离和在同一排序邻接表下的父树均保持。任意规模结论仍由保留树路径和删除不缩短路径的证明支持。
- **Q6/Q7**：枚举全部4边子集以及8种未知颜色赋值，核对6棵权5的MST和唯一合法颜色组合。
- **Q11**：独立枚举所有二路合并安排，与最小堆贪心结果交叉验证，最少读写190块。
- **Q13/Q14**：精确有理数舍入与binary32打包交叉比对；实际编译C11整数提升与赋值表达式。编译器须提供32位int，不能无条件推及所有C实现。
- **Q15/Q25/Q26/Q28/Q33/Q35/Q36/Q38/Q39**：Cache、调度、银行家安全序列、LRU、链路存储转发、交换机学习、SR接收/确认、TCP字节缓存和题定拥塞分轮模型分别模拟。
- **Q41**：参考C按 `-std=c11 -Wall -Wextra -Werror` 编译，与独立“集合求交后排序分段”基准对照。**15876组穷举有序多重集对+10000组固定种子随机样例+4组边界/例题=25880组**。逐组验证输入节点内存未改动；无结果时lo/hi保持哨兵值。
- **Q42**：真正执行AVL插入、RL旋转、指定前驱删除，检查BST/平衡因子、失败查找路径和ASL。
- **Q43**：按周期解释流水线前递、load-use冻结、EX分支和两级冲刷；最终周期13、260ps时钟、3380ps总时间。
- **Q44**：教学ISA编码/解码往返、整数与半字程序解释；两种版本和均为−1，BNZ编码均为105FFFFBH。
- **Q45**：正确方案分别向A/B发布专属通知，并等待两者分别确认。1–4条记录模型探索38/75/112/149个状态，均无重复读取、提前覆盖或死锁，且两次读取并行可达。共享ready错误模型（3条记录）探索148个状态，找到重复读取和死锁反例。**这只是有限模型检验**，一般正确性仍需依题定执行规则证明。
- **Q47**：按IPv4分片规则枚举68–1499共1432个MTU，符合观测的恰为620–627；从末片恢复总长1500 B及缺片(偏移75、总长620、MF=1)。分别模拟IP重组和TCP字节集合，核对三个已观测分组后的ACK=1001、补片后ACK=2661，并对4个分组的24种到达排列检查最终一致。故意采用“有首片和末片就提前交付TCP”的错误模型会产生错误ACK，测试可识别。

## 4. 图形验收

14张图均为纯SVG：没有嵌入脚本、外链图片、字体文件或生成式模型猜出的关键数据。机器规格哈希写入SVG元数据，重新运行 `render_figures.py --check` 必须逐字节一致。图中的节点、边、端口、表项、时序和标签由题目真值约束。

已在作者临时工作区渲染并查看所有图，检查文字、箭头、交叉线、图例与边界；Q38标签和流水线注记经过避让调整。仍未完成独立视觉审稿或A4纸实际打印试读，手机端/打印可读性需继续检验。

## 5. 不由CI证明的事项

题目新颖性、整卷难度与2024/2025的实证等效、每项干扰项的心理诊断价值、考生阅读负担、专家对C/OS/网络约定的全部解释，以及最终10/10质量。程序检查不能消除所有出题者自身建模偏差。
