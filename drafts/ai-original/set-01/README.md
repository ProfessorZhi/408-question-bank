## 构成

| 科目 | 单选 | 综合 | 分值 |
|---|---:|---:|---:|
| 数据结构 | Q1–11 | Q41=13、Q42=10 | 45 |
| 组成原理 | Q12–22 | Q43=12、Q44=11 | 45 |
| 操作系统 | Q23–32 | Q45=7、Q46=8 | 35 |
| 计算机网络 | Q33–40 | Q47=9 | 25 |
| **合计** | **40题 / 80分** | **7题 / 70分** | **150** |

Q41是带重复版本号的有序链表公共连续段算法；Q42为AVL插入、前驱删除与查找；Q43–44共享一套明确的教学ISA和流水线规则；Q45为三阶段环形缓冲与共享外设同步；Q46分析DMA完成、中断现场与进程唤醒；Q47沿同一次园区通信分析子网、ARP、TCP字节序号和吞吐上界。

相较方向稿，题图从预计8张增加到**13张学生图+1张教师专用AVL答案图**。图由结构化数据和确定性SVG代码制作，并非让生成模型猜边、猜位宽。表格、代码和纯文字能表达清楚时不强行加图。
