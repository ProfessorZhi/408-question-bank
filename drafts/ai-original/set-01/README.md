# 408 AI Original · Set 01（命题方向草稿）

> **阶段：命题立项与47题方向分配，不是学生可做的正式试卷。** 当前已定稿题目 `0/47`；学生卷与教师卷没有任何伪装成正式题面的占位题。规划目标是质量向10/10努力、**难度与2024—2025真题持平**，不是提高难度或改写现成真题。

## 项目定位

- 考试框架：150 分、180 分钟、40 道单选（80 分）、7 道综合（70 分）。
- 学科总分：数据结构45、计算机组成原理45、操作系统35、计算机网络25；选择题分布11/11/10/8。
- 题目等级预算：11道基础、23道中等、6道较难；**仅命题前估计，不是根据考生作答统计**。
- 编写原则：一道道出 → 独立验算 → 主动找反例 → 有证据的修订 → 审稿确认。哪道题质量不够就重写，不强行凑数。
- 数据参照：主分支 [2024](../../../papers/exams/2024/questions.md) / [2025](../../../papers/exams/2025/questions.md) 真题；考纲知识标签参照**尚未合并**的 [知识图谱 Draft PR #26](https://github.com/ProfessorZhi/408-question-bank/pull/26)；2027 考纲细节仍有第三方转录待正式原文核对的限制。
- **隔离边界**：仅在 `drafts/ai-original/set-01/` 工作；不向正式 `papers/` 注入不完整的47题，也不更改历史题面、源PDF、覆盖率索引、备份分支或未合并的旧PR。

## 建议先出题次序

1. 先用**数据结构 Q01–Q03**校准小题文字长度、干扰项质量和本项目的解题时间标尺；不把此前聊天里的草稿直接当作已审好的题。
2. 接着完成需要图的**Q05图遍历/Q08 B+树**，验证“真值规格 → SVG → Markdown → 解题复核”的生产链。
3. 完成1–11数据结构，积累不同难度样本，再扩至组成原理、操作系统和网络。
4. 先逐题做质量检查，再把综合题Q43–44共享机器背景的约束封存；最后做整卷审稿、限时试做与难度再平衡。
