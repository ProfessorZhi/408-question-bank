38.C。【解析】RIP 基于 UDP、OSPF 基于 IP、BGP 基于 TCP，RIP 和 BGP 均为应用层的协议，OSPF 为网络层的协议，故 I 错误；RIP 基于距离-向量路由算法，规定距离 >=16 即表示不可到达，如果网络经常动态改变，其慢收敛特性会使得网络上充斥大量无效路由信息，故 RIP 更适用于小型的、静态的互联网；OSPF 基于链路状态路由算法，它根据全网的拓扑结构采用一定算法计算最佳路由，拓扑动态改变时只是会重新计算最佳路由，更适用于大型的、动态的互联网，II 正确；RIP 规定跳数 16 表示不可达，OSPF 没有跳数的限制，III 正确；RIP 基于距离-向量路由算法，定期发送自己的完整路由表给邻居路由器，OSPF 基于链路状态路由算法，当链路状态发生变化时，将直连的链路状态洪泛发送给所有的路由器，IV 正确。故选择 C 选项。

40.D。【解析】网络应用模型主要分为 C/S 模型和 P2P 模型，大部分的应用层协议例如 DNS、FTP、HTTP、TELNET 等都是基于 C/S 模型进行设计的，选项 A 正确；C/S 模型的 Client 端只能与 Server 进行交互，与其他的 Client 交互也必须通过 Server 间接通信，选项 B 正确；P2P 模型中，每个节点不区分为服务器和客户端，既可以作为服务器，也可以作为客户端，选项 C 正确；由于各个节点的性能差异和信息的分布式传输，P2P 模型的安全性和稳定性较 C/S 模型更低，D 选项错误。

41.【解析】

（1）基数树这种数据结构不符合二叉排序树的定义。因为存在这样的根结点，根结点关键字<左孩子结点的关键字<右孩子结点的关键字。例如，在题目举例介绍的基数树中，结点 10 的左孩子是 100，右孩子是 101（灰色结点），100>10，不满足二叉排序树的定义。

（2）每个结点的关键字可以通过从树根到该结点的一条简单路径来确定。用 bool 类型的 isEnd 变量判断当前结点是否为深色结点，如果要查询的关键字已经结束，但树内当前查询的结点的 isEnd==false，则说明查找失败；同时，如果查询的过程中，无法在树内向下移动的时候，也表明查找失败。若遍历过程中匹配到非深色节点，那么查找成功。

```c
struct TreeNode {
    bool isEnd;  // 标记当前结点是否为深色结点
    string result; // isEnd == True时，result存储相应的位串的结果
    TreeNode *lChild, *rChild;
}
```

（3）可以基于基数树实现集合 S 的排序功能。将 S 中的元素按定义的规则存入基数树中（时间复杂度是 O(n)），通过先序遍历的方法，当遇到一个结点内 isEnd==true 时，输出结点内的 result。遍历一遍后，即可有序输出树内存储的元素。查找方法的时间复杂度是 O(n)。
