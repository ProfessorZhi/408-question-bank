【答案要点】

（13分）大数加法是能够对超长位数的数字进行相加，假如用不带头节点的单链表表示一个十进制数字，请设计一个空间复杂度尽可能高效的算法：LinkNode* bignumAdd(LinkNode* L1, LinkNode* L2)，实现两个大数的加法，返回结果大数的表示链表首元结点指针。
示例：结果：4321+321=4642。(十进制)
要求：
（1）给出算法的基本设计思想
（2）根据设计思想，采用C或C++语言描述算法，关键之处给出注释。
首先题意是小端存储，下列方法均有错误：看成大端，三次reverse，最多给3分简单的把结点值相加，比如567+234（小端），是不是得到7 9 （11）？没考虑进位要扣分，扣分不超过3分没考虑最后的高位进位，即没添加新节点，要扣分，扣分2分如果新增一个链表存储结果，扣1分，不符合题目要求的最小空间复杂度（参考答案给的就是开辟新的链表，要扣分）
如果转换成数组，进行计算，再转回链表，空间复杂度On，扣3分如果把大数转成longlong或其他类型，进行加法，再存进去，因为大数加法本身就是为了防止超出基本类型数据范围而设计的，扣9分，
（1）算法设计思想：
①从链表头部（十进制低位）进行加法，sum为当前节点的和，超过10的话，同步修改L1和L2的当前结点的值为
sum%10，用t存放进位信息
②当某个链表遍历结束后，应继续使用较长的链表存放结果，实现O（1）空间复杂度，运算时要加上低位的进位
③若两个链表都遍历完，仍有进位，需要在较长链表的末尾新增一个结点保存进位
④返回较长链表的首元结点的指针
(2)
ListNode* bignumAdd(ListNode* l1, ListNode* l2) {
ListNode *p = l1, *q = l2, *pre_p = NULL, *pre_q = NULL; //pre_p和pre_q记录p，
q的前驱，使最后停留在尾结点，方便最后的进位的插入结点操作
int t = 0; //记录进位信息
int len1 = 0, len2 = 0; //记录l1和l2的链表长度
while (p || q){
int sum = 0, p_val= 0, q_val = 0;   //计算当前位数的和
if (p) p_val = p->val;
if (q) q_val = q->val;
sum = p_val + q_val + t;
if (p) p->val = sum % 10;
if (q) q->val = sum % 10;
t = sum / 10;
if (p) {
pre_p = p;
p = p->next;
len1 ++ ;
}
if (q) {
pre_q = q;
q = q->next;
len2 ++ ;
}
}
if (t) {   //处理最后的进位
if (len1 > len2) pre_p->next = new ListNode(t);
else pre_q ->next = new ListNode(t);
}
return len1 > len2 ? l1 : l2;

（2）一个文件的大小为8MB，该文件的FCB里用了多少个地址项？
（3）假设某个文件的FCB已在内存，但其它信息均在外存，为了修改某个字节的内容，最少需要多少次访问磁盘？最多多少次访问磁盘？
【答案】（1）（10 + 128 + 128 * 128 + 128 * 128 * 128） * 512B（2分）
（2）12个。10个直接地址，1个一次间接地址，1个二次间接地址。（2分）
（3）最少2次，最多5次。（2分）
【解析】（1）每个磁盘块可存放512B/4B=128个盘块，因此该文件系统中一个文件的最大长度可达（10 +128 + 128 *
128 + 128 * 128 * 128） * 512B。
(2) (10 + 128) * 512 / 1024 = 69 KB < 8MB = 8192KB <（10 + 128 + 128 * 128）* 512 / 1024 = 8261KB ，最多用到二次间接地址，因此10个直接地址，1个一次间接地址，1个二次间接地址。共计12个地址项。
