42.【解析】

（1）根据中序后继的定义，如果一个结点有中序后继，则它满足两个条件的其中一条：1、有右
子树，从而中序后继为右子树的最左结点；2、无右子树但是有父结点，并且这棵树是父结
点的左孩子，中序后继为父结点。

（2）算法实现：

```c
Node *Search(Node *node) {
    if (node->right) {  //满足条件1
        Node *t = node;
        while (t->left) { t = t->left; } //找到右子树的最左结点
        return t;
    } else if (node->parent && node->parent->left == node) {
        return node -> parent; //满足条件2
    } else {                  //两个条件都不满足
        return nullptr;
    }
}
```

（3）若父结点是后继，则在 O(1) 的时间复杂度就可以获取到后继。而获取右子树的最左结点，
最坏情况下需要访问的结点数量等于树的高度。故最坏时间复杂度为 O(h)。算法不需要额
外的空间，故空间复杂度为 O(1)。h 为树的高度。

43.【解析】

（1）主存地址空间大小为 1MB，所以主存地址位数为 20 位；每个主存块大小为 16B，按字节编
址，故块内地址为 4 位；Cache 共有 32B/16B=2 行，行号占 1 位。综上，主存地址字段划分
如下：

| 标记 | Cache 行号 | 块内地址 |
| --- | --- | --- |
| 高 15 位 | 中间 1 位 | 低 4 位 |

因为采用随机替换算法和直写法，所以 Cache 行中没有替换控制位和修改位。每个 Cache 行
中包含 1 位有效位、15 位标记位和 16B 的数据，故 Cache 总容量为 2×(1+15+16×8)b=288b。
