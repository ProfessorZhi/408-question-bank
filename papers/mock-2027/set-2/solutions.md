### 第 41 题

<!-- 底本第 5—7 页；OCR 初稿，未逐字核对；其中第 6、7 页为**人工转录** -->

【答案要点】

一、简单解法：
（1）每次选取一个元素，将其改变为左右其中一个值，判断如此操作是否可以将数组变成非递减数组，不可以则还原数组后重新选取。
（2）算法实现：
```c
// 判断数组是否为非递减数组
bool nonDecrease(int *A, int n) {
    for (int i = 1; i < n; ++i) {
        if (A[i - 1] > A[i]) return false;
    }
    return true;
}

bool func(int *A, int n) {
    // 每次选取一个值进行改变
    for (int i = 0; i < n; ++i) {
        int tmp = A[i]; // 保存原来的值
        // 从左右选取一个值进行改变
        if (i == 0) A[i] = A[i + 1];
        else A[i] = A[i - 1];
        // 判断是否变成了非递减数组
        if (nonDecrease(A, n)) return true;
        // 还原数组
        A[i] = tmp;
    }
    return false;
}
```
（3）算法中需要使用循环遍历数组，循环体中用到了时间复杂度为O(n)的函数判断整体是否为非递减函数，时间复杂度为O(n²)。
二、标准解法：
（1）遍历数组，寻找递减的相邻元素，若超过一对则判断不能只改变一个元素使其变为非递减序列。若没有递减的相邻元素则判断可以。若仅有一对，则进一步判断是否可以通过调整得到非递减序列。对于清除递减部分，优先把A[i-1]大小改为A[i]；若因为没有前一个元素或者修改A[i-1]会导致A[i-2]与A[i-1]产生递减部分，则把A[i]大小改为A[i-1]。改变A[i-1]不需要修改数组，因为后续不会再检查该值，但改变A[i]则需要修改数组。
（2）算法实现：
```c
bool func(int *A, int n) {
    int count = 0; // 递减相邻元素出现的次数
    for (int i = 1; i < n; ++i) {
        if (A[i - 1] > A[i]) { // 出现递减相邻元素
            ++count;
            // 递减相邻元素超过一对，无法完成变换
            if (count > 1) return false;
            // 如果出现不能改变A[i-1]的情况，则改变A[i]
            if (i > 1 && A[i - 2] > A[i]) A[i] = A[i - 1];
            // 因为后续无需检查A[i-1]所以不用改变A[i-1]的值
        }
    }
    return true;
}
```
（3）算法中需要顺序遍历数组，时间复杂度为O(n)。

### 第 42 题

<!-- 底本第 7 页；**人工转录**（按底本页图逐字抄，来源见 `solution-pages.yml`） -->

【答案要点】

将栈S1当作输入栈，存储push()传入的数据，用于入队操作；栈S2当作输出栈，用于出队操作。每次出队时，若输出栈为空则将输入栈的全部数据依次弹出并压入输出栈，这样输出栈从栈顶往栈底的顺序就是队列从队首往队尾的顺序。
```c
stack<int> inStack, outStack;

void in2out() {
    while (!inStack.empty()) {
        outStack.push(inStack.top());
        inStack.pop();
    }
}

void enqueue(int value) {
    inStack.push(value);
}

int dequeue() {
    if (outStack.empty()) {
        if (inStack.empty()) {
            return -1;
        }
        in2out();
    }
    int value = outStack.top();
    outStack.pop();
    return value;
}

bool empty() {
    return inStack.empty() && outStack.empty()
}
```

### 第 43 题

<!-- 底本第 7 页；**人工转录**（按底本页图逐字抄，来源见 `solution-pages.yml`） -->

【答案要点】

（1）计算机时钟周期为1/500MHz=2ns，每次I/O用时5×20×2ns=200ns，设备准备16位数据用时16b/160kbps=100μs，所以最多间隔100μs必须查询一次，百分比为200ns/100μs=0.2%。
（2）中断响应和中断处理的时间为400×2=0.8μs，0.8μs<100μs，可以用中断I/O方式，百分比为0.8%。若传输率改为4MBps，则设备准备16位数据用时16b/4MBps=0.5μs，不能用中断I/O方式。
（3）设备每秒DMA次数最多为5MB/5000B=1000，百分比为1000×500×2ns/1s=0.1%。

### 第 44 题

<!-- 底本第 7—8 页；**人工转录**（按底本页图逐字抄，来源见 `solution-pages.yml`） -->

【答案要点】

（1）每条指令占2个字节，且PC增量为2，所以编址单位为字节。指令字长固定是RISC的设计风格。
（2）无符号比较时，判断表达式中不会出现OF，所以bgt指令执行的是带符号整数比较。
因为指令系统有54条指令，支持4种寻址方式，所以OP为6位，MOD为2位，OFFSET
为16-6-2=8位，由于用补码表示，故偏移量范围为-128~127（写出这个即可给分），转移目标地址范围是(PC)+2+(-128×2)~(PC)+2+127×2，即转移目标地址的范围是相对于bgt指令的前254个单元到后256个单元之间。
对于单地址指令，OP和MOD位数与bgt指令相同，直接寻址范围为8位无符号数取值范围，即0~255。
（3）①存放指令，部件是指令寄存器IR；②这里需要把OFFSET（带符号整数）与PC（无符号整数）相加，要对补码表示的带符号整数进行符号扩展，所以是符号扩展器；③根据bgt指令判断表达式的结果选择指令执行结果，该部件为多路选择器。

### 第 45 题

<!-- 底本第 8 页；**人工转录**（按底本页图逐字抄，来源见 `solution-pages.yml`） -->

【答案要点】

```c
semaphore mutex = 1; //用于保护更新count变量时的互斥
semaphore lock = 1; //用于保证读者和写者互斥地访问文件
semaphore read = 1; //用于保证写进程对F的修改被读取过
int readcount = 0; //用于记录当前的读者数量

writer(){ //写者进程
    while(TRUE){
        P(read); //共享文件被读取过才能写入
        P(lock); //互斥访问共享文件
        writing; //写入
        V(lock); //释放共享文件
    }
}

reader(){ //读者进程
    while(TRUE){
        P(mutex); //互斥访问count变量
        if(count == 0) //当第一个读进程读共享文件
            P(lock); //阻止写进程写
        count++; //读者计数器加1
        V(mutex); //释放互斥变量count
        reading; //读取
        P(mutex); //互斥访问count变量
        count--; //读者计数器减1
        if(count == 0){ //当最后一个读进程读完共享文件
            V(lock); //允许写进程写
            V(read); //共享文件经过至少一个读者的读取
        }
        V(mutex); //释放互斥变量count
    }
}
```

### 第 46 题

<!-- 底本第 8—9 页；**人工转录**（按底本页图逐字抄，来源见 `solution-pages.yml`） -->

【答案要点】

（1）1B9DH=0001 1011 1001 1101B，页面大小1KB，页内地址占10位，则前六位为页号：00
0110B=06H。根据FIFO算法，要替换装入时刻最早的页，即2号页，所以物理地址为0001
1111 1001 1101B=1F9DH。
（2）根据LRU算法，要替换最近访问时间最早的页，即1号页，所以物理地址为0000 1111 1001
1101B=0F9DH。
（3）根据改进型CLOCK算法，从3号页框开始，第一轮即前4次查找页框号的顺序为3→4→
7→1，未找到访问位和修改位均为0的页。第二轮查找中，寻找访问位为0修改位为1的页，同时将查找失败的页的访问位置0，最终要替换掉3号页，同时把其余页面访问位置0。
结果如下表所示。

| 页号 | 页框号 | 装入时刻 | 最近访问时间 | 访问位 | 修改位 |
| --- | --- | --- | --- | --- | --- |
| 0 | 4 | 28 | 178 | 0 | 0 |
| 1 | 3 | 121 | 159 | 0 | 0 |
| 2 | 7 | 19 | 185 | 0 | 1 |
| 6 | 1 | 190 | 190 | 1 | 0 |

【答案要点】

（1）建立TCP连接时的序号为1000，在整个建立连接的过程中，只有第一次握手会消耗序号，所以一共会消耗4001个序号，第一次挥手的报文的序号为5001；第一次挥手的报文一定为
1的字段只有FIN，其他字段均可能不为1；
（2）从第一次挥手报文的发送开始，主机至少需要1个RTT和2MSL的时间才能进入到CLOSED
状态，即最短的时间为900ms；
（3）主机H和Web服务器均使用的内部地址，需要经过NAT转换，R3收到的分组的源IP地址为200.101.10.5，目的IP地址为200.101.1.2；Web服务器收到的分组经过NAT转换后，目的地址变为192.168.20.3，源地址依旧为200.101.10.5。
