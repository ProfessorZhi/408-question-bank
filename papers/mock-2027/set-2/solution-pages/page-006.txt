一、简单解法：
（1）每次选取一个元素，将其改变为左右其中一个值，判断如此操作是否可以将数组变成非递减
数组，不可以则还原数组后重新选取。
（2）算法实现：

```c
// 判断数组是否为非递减数组
bool nonDecrease(int *A, int n) {
    for (int i = 1; i < n; ++i) {
        if (A[i - 1] > A[i]) return false;
    }
    return true;
}

bool func(int *A, int n) {
    // 每次选取一个值进行改变
    for (int i = 0; i < n; ++i) {
        int tmp = A[i]; // 保存原来的值
        // 从左右选取一个值进行改变
        if (i == 0) A[i] = A[i + 1];
        else A[i] = A[i - 1];
        // 判断是否变成了非递减数组
        if (nonDecrease(A, n)) return true;
        // 还原数组
        A[i] = tmp;
    }
    return false;
}
```

（3）算法中需要使用循环遍历数组，循环体中用到了时间复杂度为O(n)的函数判断整体是否为
非递减函数，时间复杂度为O(n²)。
二、标准解法：
（1）遍历数组，寻找递减的相邻元素，若超过一对则判断不能只改变一个元素使其变为非递减序
列。若没有递减的相邻元素则判断可以。若仅有一对，则进一步判断是否可以通过调整得到
非递减序列。对于清除递减部分，优先把A[i-1]大小改为A[i]；若因为没有前一个元素或
者修改A[i-1]会导致A[i-2]与A[i-1]产生递减部分，则把A[i]大小改为A[i-1]。改
变A[i-1]不需要修改数组，因为后续不会再检查该值，但改变A[i]则需要修改数组。
（2）算法实现：

```c
bool func(int *A, int n) {
    int count = 0; // 递减相邻元素出现的次数
    for (int i = 1; i < n; ++i) {
        if (A[i - 1] > A[i]) { // 出现递减相邻元素
            ++count;
            // 递减相邻元素超过一对，无法完成变换
            if (count > 1) return false;
            // 如果出现不能改变A[i-1]的情况，则改变A[i]
            if (i > 1 && A[i - 2] > A[i]) A[i] = A[i - 1];
            // 因为后续无需检查A[i-1]所以不用改变A[i-1]的值
        }
    }
    return true;
}
```
