对于单地址指令，OP和MOD位数与bgt指令相同，直接寻址范围为8位无符号数取值范围，即0~255。
（3）①存放指令，部件是指令寄存器IR；②这里需要把OFFSET（带符号整数）与PC（无符号
整数）相加，要对补码表示的带符号整数进行符号扩展，所以是符号扩展器；③根据bgt指
令判断表达式的结果选择指令执行结果，该部件为多路选择器。

semaphore mutex = 1; //用于保护更新count变量时的互斥
semaphore lock = 1; //用于保证读者和写者互斥地访问文件
semaphore read = 1; //用于保证写进程对F的修改被读取过
int readcount = 0; //用于记录当前的读者数量

writer(){ //写者进程
    while(TRUE){
        P(read); //共享文件被读取过才能写入
        P(lock); //互斥访问共享文件
        writing; //写入
        V(lock); //释放共享文件
    }
}

reader(){ //读者进程
    while(TRUE){
        P(mutex); //互斥访问count变量
        if(count == 0) //当第一个读进程读共享文件
            P(lock); //阻止写进程写
        count++; //读者计数器加1
        V(mutex); //释放互斥变量count
        reading; //读取
        P(mutex); //互斥访问count变量
        count--; //读者计数器减1
        if(count == 0){ //当最后一个读进程读完共享文件
            V(lock); //允许写进程写
            V(read); //共享文件经过至少一个读者的读取
        }
        V(mutex); //释放互斥变量count
    }
}

（1）1B9DH=0001 1011 1001 1101B，页面大小1KB，页内地址占10位，则前六位为页号：00
0110B=06H。根据FIFO算法，要替换装入时刻最早的页，即2号页，所以物理地址为0001
1111 1001 1101B=1F9DH。
（2）根据LRU算法，要替换最近访问时间最早的页，即1号页，所以物理地址为0000 1111 1001
1101B=0F9DH。
（3）根据改进型CLOCK算法，从3号页框开始，第一轮即前4次查找页框号的顺序为3→4→
7→1，未找到访问位和修改位均为0的页。第二轮查找中，寻找访问位为0修改位为1的
