## 4. 源文异文登记（保留原文，未改写）

按 `docs/qa-policy.md` §6：**发现源文自身写法与常规不符时，保留原文并登记，不代为"修正"**。

1. **`inde-gree`（Q41）**：源页写「出度 outdegree 和入度 **inde-gree**」（带连字符），同段后文又写 `indegree`。
   700 dpi 复核确认是**源文自身不一致**，未统一。
2. **`print Vertices`（Q41）**：函数名在源页 `print` 与 `Vertices` 之间**有空格**。C 语法上应为 `printVertices`，未改。
3. **全角引号（Q41）**：`printf(“%c”, G.VerticesList[k]);` 用的是 `“` `”`，不是 ASCII `"`。700 dpi 复核确认，未改。
4. **`return  count;`（Q41）**：两个空格，保留。
5. **`0040  10B9H`（Q44）**：源页该处空白比 (2) 的 `0040 1079H` 明显更宽。两处都是**单个 32 位地址**的 4+4 分组
   （`004010B9H` / `00401079H`），**值本身无歧义**；成品统一按单空格书写，差异记于此。
6. **逗号宽度（Q45）**：文本层把第一处逗号输出为全角 `，`，但 550 dpi 渲染图两处均为半角 `, `。
   取渲染图的半角，**文本层与图像不一致**这一事实记于此。
   另：修改后的语句源页写作 `while (key == TRUE)swap key, lock`，`)` 与 `swap` 之间**无空格**，保留。
7. **`*` 与 `10³`（Q47）**：源页用 `*` 而非 `×` 表示乘方；文本层把上标 `³` 抽成普通数字（`300*103B/s`），
   600 dpi 渲染图确认是**10 的三次方**，已还原为 `10³`。
