## 3. 容易误读的考试范围细节（优先级高）

| 范围点 | 第三方2027考纲可定位的条目 | 王道目录与教学解释 | 命题处理意见 |
|---|---|---|---|
| 红黑树 | 查找 → 树形查找 | 王道第 7 章也讲红黑树 | **保留为核心候选考点**；不能因相对难而忽略 |
| KMP/字符串模式匹配 | 查找 → 字符串模式匹配 | 王道把串单设第 4 章，部分串定义打星号 | **主概念放在查找领域**；串的基础存储可作前置教学，不能让目录组织改变大纲归属 |
| B 树 vs B+ 树 | B 树及其基本操作；B+ 树的基本概念 | 王道两者均设专节 | **深度不对称**：B树的插删操作与B+树的基本概念不能机械要求同深度 |
| 计数排序 | 在官方排序方法的公开枚举中不单列 | 王道 `*8.5.3` 介绍 | 作为**教材延伸**，不占用模拟卷“必须覆盖”的独立配额；也不宣称永不出现 |
| 欧拉路径 | 公开图应用栏没有单独命名 | 可由图的度/路径性质延伸；历史题可见 | **有历史命题证据**，但不要虚构为 2027 正式新增的一条考点 |
| 段式、段页式虚拟存储 | CO 存储系统 → 虚拟存储器分别列出 | 王道第 3 章存储体系里分解 | 应从现有“页表”概念进一步拆分，避免只会算分页 |
| SIMD/MIMD/SMP | CO 中央处理器 → 多处理器基本概念 | 王道 CPU 章节讲基本模型 | 保留分类和基本协同概念，不据教材延伸章节要求实现大型处理器 |
| 条件变量 | OS 同步与互斥 → 条件变量 | 王道目录将相关机制放在管程等节内 | **公开考纲点名**，不能因为王道章标题没写“条件变量”就漏掉 |
| 宏内核/微内核/外核 | OS 操作系统结构 | 王道第 1 章讨论内核结构 | 外核不是在此范围之外；保留组织方式及概念区别 |
| 内存映射文件及 I/O 接口 | OS 内存管理与 I/O 管理分节列出 | 王道对应两个章节均有内容 | 适合结合系统调用、页表与设备读取过程进行场景题 |
| 数据报与虚电路 | CN 物理层 → 通信基础 | 王道网络层章节也介绍两种服务模型 | 注意**考纲栏目归属**和王道解释场景不同，不据书章名重新分配考纲 |
| FDM/TDM/WDM/CDM + 令牌 | CN 数据链路层 → 介质访问控制 | 王道第 3 章分成信道划分/随机/轮询 | 把正交信道划分和竞争型接入分开，现有单节点偏粗 |
| SDN | CN 网络层功能 | 王道第 4 章有 SDN 基本概念 | 可考控制平面与数据平面分工，避免超纲编造控制器实现细节 |
| IPv6 过渡与 IGMP | 公开2027条目主要要求 IPv6 地址/特点及 IP 组播概念/地址 | 王道还设“IPv4 向 IPv6 过渡”“IGMP 与多播路由” | 目录额外解释可作训练，不自动成为独立必考点 |
| MIME 邮件格式 | CN 应用层 → 电子邮件格式和 MIME | 王道应用层同样列有格式及 MIME | 从现有 SMTP/POP3 合并节点中细化出格式协议与内容编码 |

## 4. 旧 217 节点与 2027 范围的对账结果

- [完整原 217 个知识点](../concepts.json) 仍保留 ID，不更名、不删除；对应 [217 行考纲交叉映射](concept-crosswalk.csv)。
- **216/217** 现有节点关联到至少一个考纲范围中的编辑学习单元；余下 `DS05.10` 为欧拉路径——历史题中有证据，但不属于公开考纲明确单列标题。
- [18 个候选增补点](gap-review.md) 已明确分成：公开转录明确且现有节点粒度不足、王道训练展开、两者混合。**这份清单不是“18 个新增考纲考点”。**
- 本仓库 [四科具体学习目标](README.md) 共 **127 单元、426 条原创训练要点**，可用于拟定原创试题的考点和能力边界，不作为考频统计原始数据。

## 5. 版本差异不应过度断言

四〇八档案室公开页面文字声明 2027 相较 2026 没有变动。当前仅确立网页公开声明和 2027 版书目的存在，**尚未将正式 2026 与 2027 官方正版逐条原文互校**。若未来能取得授权使用的 2027 原版，应优先核验：考试目标、四科条目、星号标记并非考试官方符号、各子项变化。
