# 2027 年 408 计算机组成原理：考纲知识点与王道细化

> 以2027公开考纲转录的考试栏目为骨架，对照王道2027版出版社目录；每项训练目标是原创解读，不是正式考纲逐字引文。

## 教材及训练的额外边界

| 议题 | 归属 | 注释 |
|---|---|---|
| RISC-V或特定指令集编码示例 | outline-derived | 官方要求机器级程序及RISC/CISC基本原理，不能由书中示例推导“唯一指定ISA” |
| 数字电路门级细节 | background-support | 加法器/ALU是明确范围，但单独数字逻辑设计应依是否用于理解题干决定 |
| 高级微结构推测与完整乱序执行细节 | textbook-additional | 官方明确超标量和动态流水线基本概念，不能等同完整高端处理器微结构设计要求 |
| SSD控制器内部算法 | textbook-additional | 官方CO说明SSD，具体主控/FTL算法深度需和大纲原文或真题核对 |
