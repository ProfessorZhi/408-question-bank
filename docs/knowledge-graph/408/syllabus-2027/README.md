# 2027 考研 408：考试范围与王道目录精细化对照

> **研究基线：2026-10-20。性质：课程编辑整理稿，不是官方考纲扫描件或王道教材原文。** 本目录专门回答“考纲究竟覆盖什么、王道讲到哪里、AI 应该考到什么深度”。

## 已核实的证据等级

1. **官方出版物存在性（已核实）**：教育部教育考试院署名的《2027年全国硕士研究生招生考试计算机学科专业基础考试大纲》已由高教社登记，ISBN `978-7-04-068451-3`，出版日期 `2026-09-29`。[书目](https://www.hep.com.cn/book/show/2099763850751057921)。**未获得可全文逐字比对的官方正版内容**。
2. **2027 考纲细目（公开第三方转录）**：[四〇八档案室 2027 考纲](https://zhenti.beokayy.club/outline) 是本目录核对具体分节名称及显式范围的来源；网站声称 2027 与 2026 无变动，但此结论未经官方全文比对。
3. **王道书籍章节（出版社目录）**：2027 版四科均已找到电子工业出版社公布的书目与目录，可核实章节、辅助方法和星号条目，但教材在 **2026-01** 出版，早于上面的正式 2027 考纲。**书中出现某算法 ≠ 官方独立考点**。
4. **我们的训练目标（原创拆解）**：以下 127 个学习单元、426 个能力目标由本项目编写，是为了检验是否真的“掌握、理解、会算、会证明、会编程”；不能与官方原文混同。
5. **已有知识点（217 个稳定 ID）**：在 `../concepts.json` 中存储；与本目录的 127 单元用 `concept-crosswalk.csv` 映射。修改稳定 ID 需另立迁移计划，不能破坏 799 道真题索引。

## 对原知识图谱的查漏结果

- [217 节点考纲对照表](concept-crosswalk.csv)：**216 个节点**能对应到至少一个 2027 公开考纲范围的编辑学习单元。
- 现有 `DS05.10 欧拉路径与图结构判定` 有历史真题证据，但**没有在公开考纲中被单独命名**；不能据此认定考纲外不考。
- [18 条待审的细化与扩展提案](gap-review.md)，[机器数据](gap-proposals.json)：其中带有 `outline-explicit-finer-granularity` 标签的建议，是“考纲转录已明确提及、目前 217 节点尚未独立拆分”的情况；`book-extension` 是王道教材讲授、但不能直接断言为单列范围的内容。
- **不要直接把 18 条提案插入 `concepts.json`**：会改变已有关系和题目分类的语义；应先人工审稿、确定增补 ID 和父子关系，再由新 PR 处理。

## 对原创 408 模拟卷的使用规则

1. 对于考纲公开转录**明确列出的**知识点，可作为正式覆盖候选（红黑树、条件变量、信道划分与轮询访问、SMP、SDN 等）。
2. 对于教材介绍的**具体实现技巧**，先判断它是否只是考纲大项的训练方法（例如败者树是外部排序技术），不要机械计算“未考比例”。
3. 对于王道额外章节（例如计数排序），可用于辅助理解或创新训练，但不作为必须占用 150 分预算的独立强制点。
4. 每道原创题记录 `primary_concept`、`syllabus_section_id`、王道目录来源、需要的先修知识和认知操作，综合题也记录跨科概念。
5. 对出现歧义的“是否必考”问题，不作预测式断言；引用官方考纲原文或者列出 `requires-official-text` 人工核对任务。
6. 每题单独验算、作最小反例与干扰项分析；有图题应验证图结构的数据真值，不能只靠视觉生成模型。
