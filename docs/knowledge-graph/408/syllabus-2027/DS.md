# 2027 年 408 数据结构：范围与王道目录精细化解读

> 依据 2027 大纲公开转录的栏目、王道 2027 版出版社目录；以下训练目标为本项目原创拆解，不是考纲逐字引用。
> 主要目标：区分掌握、理解、算法设计和复杂度论证。数据结构分值约 45 分。

## DS01 基础概念与算法

### 数据结构术语与逻辑模型

知识图谱：`DS01.01`

- 区分逻辑结构和存储结构
- 区分数据类型、ADT和基本操作
- 依据访问/修改要求选择存储方式

### 算法基本性质与评价

知识图谱：`DS01.02`、`DS01.03`、`DS01.04`、`DS01.05`

- 分析正确性与终止性
- 计算循环与递归时间复杂度
- 辨析最坏/平均代价与递归栈空间

## DS02 线性表

### 线性表的算法应用
