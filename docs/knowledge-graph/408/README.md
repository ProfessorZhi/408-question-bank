## 使用方法

**复习：** 从概念图选知识节点，按“前置知识”关系梳理学习路径，再从真题索引定位原题；前置关系是编辑假设，待教研审核。

**AI 出题：** 每题选一个主知识节点、必要的辅助节点和认知操作（模拟、边界反例、推导、程序设计、跨层机制）；每个错误选项必须对应具体误解。原创图必须逐项核对标号、边方向、权值、位宽、时序、地址及题干一致性。

**统计：** 不把候选标签当成已证实的历史频率。不把“目前没标到”的知识点认定为“过去从未考过”；跨学科综合题可以包含多个考点，但当前统计仅对主标签计一次。

只读校验本知识图谱：

```bash
python docs/knowledge-graph/408/check.py
```
