## 3. 命题策略

- **核心知识点**：每题必须从 [`concepts.json`](concepts.json) 选择主节点，可以另选前置和跨学科节点。绝不为“命中热门关键词”强行塞入无关考点。
- **认知操作**：至少明确一种真实操作——结构模拟、条件推演、边界构造、复杂度论证、程序设计、跨层地址/时序计算、性质证明或最小反例。
- **干扰项诊断**：每个错误选项须对应具体的、可重现的错误路径（如遗漏进位、误用首次适应、忽略窗口回退、把物理地址与虚拟地址混为一谈）。
- **知识图谱防重复**：与历史题比较的应是“题意约束 + 推理机制”，不是题面文本相似度。改数字、改人物、改拓扑名字不算有创造性的命题。
- **空白与新点**：217 个节点中少题/无标签的条目仅表示当前索引缺证据；是否纳入原创题取决于当年正式考纲、重要性与整卷平衡。

## 4. 原创插图质量门禁

图可以自绘/AI 辅助设计，但图中**符号和拓扑正确性**高于视觉效果。图算法的边集、方向、权值应有机器可读的真值表；CPU 数据通路的位宽、控制线、端口归属应有结构清单；网络图的前缀、端口、MTU、时序必须与题干逐项比对。对于高精度结构图，优先可校验的 SVG/Graphviz/脚本绘制，再进行可读性排版。未经人工目视和数据核对的生成图不能定稿。

建议 `drafts/ai-original/set-01/` 单套一目录：`questions.md`（无答案）、`solutions.md`、`review.md`、`blueprint.md`、`assets/`；草稿不放在现有 `papers/` 下，以免未满 47 题破坏旧 CI。

## 5. 每道题的发布门禁

1. 条件充分，题干不依赖未声明约定；正确项**唯一且有独立推理证明**。
2. 四个选项均有可解释的逻辑地位；一眼排除两个弱选项的题退回重写。
3. 数值题用独立脚本或第二套推导复核；算法题给出复杂度证明与极端边界样例；同步题检查死锁与活性。
4. 跨层综合题确认所有地址、周期、缓存、协议状态相容；有插图时同时验证图与文本。
5. `questions.md` 禁止答案泄漏；`review.md` 记录误判、修改、淘汰原因；只有通过审稿才计入 47 题。
6. 题目定稿由人工审查决定。没有考生试做数据，不能把预估难度/区分度冒充心理测量结果。

## 6. 长期用途

知识图谱不止服务出卷，也可用于“错题 → 缺失前置概念 → 推荐复习路径”；但这需要将已审核的关系与实际作答数据关联，不能仅凭关键词触发自适应结论。
