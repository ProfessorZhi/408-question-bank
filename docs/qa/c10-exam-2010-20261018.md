## 3. 方法

1. **先独立解算，再与答案对照。** 选择题先自行推出唯一项并写出排除依据；综合题先给出推导/单位/算法与数值，再读 `solutions.md`。
2. **答案键独立读取。** 答案 PDF 文本层把 8 列 × 5 行的答案表线性化成一行，容易误读；因此将第 1 页 150dpi 渲染后**目视直读答案表**，确认：
   - 1–8：D C D C B A C B
   - 9–16：B D A D B B D A
   - 17–24：D B A D A D A C
   - 25–32：B A D B B C C B
   - 33–40：C C D C B D A A
   与 `solutions.md` 的 40 条逐题答案完全一致。
3. **计算验算。** 用单线程 Python 脚本对可枚举/可计算项复核（散列、AVL、拓扑序、补码溢出、最佳适配、Cache、磁盘、CSMA/CD 等），输出见 §6。
4. **图表定点目视。** Q3、Q4、Q8、Q34、Q45、Q46 的图均在原 PDF 页面渲染后裁切、放大目视；未凭 OCR 推断。Q3 的 300dpi 裁图用于判读线索箭头方向。
5. **不把机器结构 PASS 当学术 VERIFIED。** 47 条状态都来自逐题人工解算；JSONL 的 `independent` 与 `evidence` 分开记录「我的结论」和「对照证据」。
