#### Q42（15 分）两等长升序序列的中位数 — CONTENT_ERROR（参考代码）

**设计思想（正确）**：分别取 A、B 的中位数 a、b；若 a=b 返回；若 a<b，等长舍弃 A 的较小一半与 B 的较大一半；若 a>b 反之；直至两序列各剩 1 个元素，取较小者。复杂度 **O(log n)**，空间 **O(1)**。

**参考答案的代码错误**：答案册 p10 在「元素个数为偶数且 a>b」分支印为：

```c
else {                 // 元素个数为偶数
    d1 = m1 + 1;       // 舍弃 A 中间点以后部分，且保留中间点
    s2 = m2;           // 舍弃 B 中间点及中间点以前部分
}
```

该分支可使区间**原地不动**。反例：

- `A=[1,2]`, `B=[0,0]`, n=2
- `m1=0, m2=0`，`A[m1]=1 > B[m2]=0`
- `(s1+d1)=1` 为奇数 → `d1=m1+1=1, s2=m2=0`
- 状态仍为 `(s1,d1,s2,d2)=(0,1,0,1)` → **死循环**

**候选修正（未落盘、未改参考文件）**：偶数分支改为 `d1=m1; s2=m2+1;`（对称于 a<b 分支的 `s1=m1+1; d2=m2;`）。以该修正实现做 24,000 组 n=1..8、含重复值的随机/穷举测试，全部返回合并序列第 n 小（即 ⌈2n/2⌉ 位），**0 失败**。

> 按任务约束，真实错误需第二 Agent 复核后另建候选修正；本报告只定位与给出反例，**未修改** `solutions.md`。

#### Q44（12 分）虚拟地址、Cache、TLB — VERIFIED

- 虚拟地址：16MB=2²⁴ ⇒ **24 位**；页大小 4KB=2¹² ⇒ 高 **12 位**为虚页号，低 12 位页内偏移。
- 物理地址：1MB=2²⁰ ⇒ **20 位**；高 **8 位**为页框号。
- 物理地址字段：块大小 32B ⇒ 块内地址 **5 位**；Cache 8 行 ⇒ 行号 **3 位**；标记 **20−5−3=12 位**。即 `[19:8] 标记 | [7:5] 行号 | [4:0] 块内`。

(3) VA=001C60H：VPN=001H，页表项有效、页框=04H ⇒ PA=**04C60H**。行号=(PA>>5)&7=**3**，标记=PA>>8=**04CH**；行 3 有效但标记为 **105H** ≠ 04CH ⇒ **Cache 不命中**。
(4) VA=024BACH：VPN=024H；TLB 2 组（8/4），组号=VPN&1=**0**，标记=VPN>>1=**012H**；组 0 中存在有效项 012H（页框 1F）⇒ **TLB 命中**，页面在主存。参考 p10–11 与本报告一致。

#### Q45（8 分）银行取号/叫号同步 — VERIFIED

```text
semaphore empty=10;   // 空座位数
semaphore mutex=1;    // 取号机互斥
semaphore full=0;     // 已占座位数
semaphore service=0;  // 等待叫号

process 顾客 i {
    P(empty);
    P(mutex);
    从取号机取号;
    V(mutex);
    V(full);
    P(service);
    接受服务;
}
process 营业员 {
    while (TRUE) {
        P(full);
        V(empty);
        V(service);
        为顾客服务;
    }
}
```

P/V 配对平衡：`empty` 顾客 P / 营业员 V；`full` 顾客 V / 营业员 P；`service` 营业员 V / 顾客 P。`P(empty)` 在 `P(mutex)` 之前，避免持锁等座；无死锁。与参考 p11 印刷代码一致。

#### Q46（7 分）一级目录、一次写入文件系统 — VERIFIED

(1) **连续结构**更合适：文件一次写入、不可修改，无须动态增长/再分配；连续分配顺序与随机访问都高效，寻道少。FCB 字段：**起始块号 + 块数**（或起始块号 + 结束块号）。
