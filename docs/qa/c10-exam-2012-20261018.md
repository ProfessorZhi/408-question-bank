## 3. 缺陷与候选修正（**未擅改**）

### D1 · Q1 源题面 `fact(n-10)`（SOURCE_ORIGINAL_ERROR）

- 位置：paper p1；`questions.md` 第 19–23 行。
- 事实：底本印刷体与文字层均为 `return n*fact(n-10)`；答案 p1–p2 的解析按 **`n-1`** 递推
  （`T(n)=T(n-1)+1`）。
- 影响：答案 B（O(n)）在两种读法下都成立；但题面按字面不可读作阶乘。
- 候选修正（**待第二 Agent 复核后另建**）：`fact(n-10)` → `fact(n-1)`；若确认底本原样，
  则保留并在题注标明“底本排版缺陷”。

### D2 · Q14 选项丢失上标（TRANSCRIPTION_ERROR）

- 位置：paper p2 目视 vs `questions.md` 第 194–199 行。
- 事实：源页为 `2^126−2^103`、`2^127−2^104`、`2^121−2^103`、`2^128−2^104`；
  仓库写成 `2126－2103`、`2127－2104`、`2121－2103`、`2128－2104`。
- 影响：答案 D 仍可还原，但选项文本**字面错误/歧义**。
- 候选修正：恢复 LaTeX 上标 `$2^{126}-2^{103}$` 等。

### D3 · Q42 C 代码 OCR 乱码（TRANSCRIPTION_ERROR）

- 位置：answer p9 清晰印刷体 vs `solutions.md` 第 295–303 行。
- 事实：仓库代码出现 `豆n妞ode`、`F:irict'h七ComniortlLinkList`、`ɤ`、`ɧ0立` 等乱码；
  答案页印刷体是可读的 `LinkNode *Find_lst_Common(LinkList str1, LinkList str2)`。
- 影响：算法思想、复杂度正确；代码不可直接编译/引用。
- 候选修正：按 answer p9 重录代码（设计思想与复杂度不变）。

### D4 · Q47 源答案截断 + 分组表异常（SOURCE_ORIGINAL_ERROR）

- 位置：answer p11；`solutions.md` 第 393–394 行在“所以 S 已经收到的应用层数据的字节数”处结束。
- 事实：
  - (2) 的字节数 **未印出**；(3) 整段 **缺失**。

## 5. 代码实验（低负载、可复现）

脚本：`scratch-c10-exam-2012-20261018/verify_c10.py`（单线程，标准库）。
一次运行的关键输出：

```text
Q2  stack max (incl parens) = 5                     -> A
Q7  Dijkstra order = a0 b2 c3 f4 d5 e6              -> C
Q17 hits: (addr>>1)&1 = 3 ; addr%2 = 1              -> C（底本约定）/ A（常规约定）
Q27 Available=(2,3,3); D 全程可满足，A/B/C 分别阻塞 -> D
Q36 t_frame=64ms, cycle=668ms, W=11, seq bits=4     -> B
Q39 network=180.80.76.0, broadcast=180.80.79.255    -> D
Q41 Huffman cost=825; subset-DP optimum=825; 顺序合并=850
Q45 (0,4)->frame21; (1,11)->reuse32; (2,14)->frame41
Q46 blocks=2^32, 4B/entry, direct=128KB; cont=2^26B, direct=84KB
Q47 pkt4 payload=16B; TTL(47-b)=64, TTL(pkt5)=49 => 15 hops
```

另做 Q47 首部解析：5 个分组的 src/dst/seq/ack/flags/总长；2 号按 `0x43` 直接解析会得到非法
IHL=12，按上下文以 `0x45`（IHL=20）解析则得到 `SYN+ACK, seq=e0599fef, ack=846b41c6`，与解析文一致。
这佐证 `0x43` 是底本笔误而非题意。
