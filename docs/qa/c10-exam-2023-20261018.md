## 5. Q41–Q47 逐题结论

### Q41（13 分）— `SOURCE_ORIGINAL_ERROR`（算法语义独立正确）

- **独立推导**：出度 = 第 k 行之和 `Σ_m Edge[k][m]`；入度 = 第 k 列之和
  `Σ_m Edge[m][k]`。对题图（a→b, a→d, b→c, b→d, c→d）：
  a 出 2 入 0、b 出 2 入 1、c 出 1 入 1、d 出 0 入 3 ⇒ **K={a,b}，返回 2**。
- 参考代码的控制流与上述推导一致（双重循环 O(n²)，`outdegree>indegree` 输出
  `VerticesList[k]` 并计数），**算法正确**。
- **源原印错误**（150 dpi 复核 p11–12，`qa-policy §6` 保留不改）：
  1. 函数名印作 `print Vertices`（`print` 与 `Vertices` 之间有空格；题面本身写的是
     `printVertices`）；
  2. 入度变量先写 `inde-gree`、后面又写 `indegree`，源文自身不一致；
  3. `printf(“%c”, …)` 用全角引号；
  4. `return  count;` 为两个空格。
- **处置**：不改 `solutions.md`，不合并；等第二独立 Agent 复核后再决定是否提源文修正。

### Q42（10 分）— `VERIFIED`

- 置换-选择（m=4）逐记录模拟，输出恰为：
  `37,51,63,92,94,99` / `14,15,23,31,48,56,60,90,166` / `8,17,43,100`。
- 首段长度上界 `n`（输入已升序时可全出一段）；下界 `m`（初始 m 个记录必可按序输出；
  300 组随机排列检验无一首段 < m）。参考的“最大 n、最小 m”正确。

### Q43（14 分）— `VERIFIED`

- 数组 6144B，起址 `0x422000` 页内偏移 0 → 跨 `0x422`、`0x423` 两页；首访与
  `a[16][0]`（`0x423000`）各一次缺页，共 **2 次**。
- 无时间局部性：每个元素只访问 1 次。
- Cache：8KB/32B=256 块，4 路 → 64 组，组号 6 位（A10–A5），块内 5 位（A4–A0）；
  `a[1][0]=0x422000+256=0x422100`，组号 `(0x422100>>5)&0x3F = 8`。
- 192 个主存块；全量 LRU 模拟（仅数组访问）两种循环均
  **hits=1344 / misses=192 / 1536 次 → 87.5%**（每组建 3 块 ≤ 4 路，无替换）。

### Q44（9 分）— `VERIFIED`

- 第 19 条 11 字节：`C7 84 82 00 20 42 00 0A 00 00 00`；
  `0x4010AE + 11 = 0x4010B9`。
- `jmp EB 09` 与 `jge 7D 32` 均为相对寻址；`0x401079+2+09 = 0x401084`
  （`0x40108A+0x32 = 0x4010BC` 亦吻合）。
- 源操作数立即数寻址；`ecx+edx*4+0x422000` 中 `edx=j` ⇒ `ecx=i×256`；
  地址字节 `00 20 42 00` 为小端。
- 首次执行第 19 条取指不缺页：指令页号 `00401H` 已驻留。

### Q45（7 分）— `VERIFIED`

- 进入区 `if` 改为 `while`（lock 已真时单次 swap 后 key 仍真，会误入临界区）；
  退出区 `lock=TRUE` 改为 `lock=FALSE`。
- 不能以 `newSwap` 代替：其读-改-写可被并发交错，不保证两变量原子交换，
  可能使两个线程同时进入临界区。

### Q46（8 分）— `VERIFIED`

- 正确顺序：`②`（无数据，阻塞）→ `⑥`（用户输入）→ `④`（启动键盘中断处理）
  → `③`（驱动读入系统缓冲）→ `①`（唤醒入就绪）→ `⑤`（系统调用返回）。
- 故 ① 前为 ③、后为 ⑤；⑥ 后为 ④；② 后必切换；① 后调度程序才可选中 P；
  ③ 属键盘驱动；中断处理时 P 为阻塞态、CPU 为内核态。

### Q47（9 分）— `VERIFIED`

- 控制连接持久、数据连接非持久；登录建立的是控制连接。
- 首数据字节序号 `100+1=101`；18000B 后末字节 18100，客户端 FIN 18101，
  服务器第二次挥手 ACK = **18102**。
- 慢开始 1→2→4，拥塞避免每 RTT +1：各 RTT 发 1,2,4,5,6 段 = 18 段；
  ACK 2101 时 **3MSS**，ACK 7101 时 **5MSS**。
- 5 个数据 RTT + 1 个建链 RTT = **6RTT=60ms**；
  平均速率 `18000B/60ms=300×10³ B/s=2.4Mb/s`。
- 口径说明见 §6.6。
