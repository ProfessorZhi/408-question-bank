## 4. Q41–47 独立作答与核对

### Q41（13 分，BST 判定）— `SOURCE_ORIGINAL_ERROR`

**独立算法**：顺序存储根在 `SqBiTNode[0]`，左孩子 `2i+1`、右孩子 `2i+2`，`-1` 为空。做中序遍历（左-根-右），用全局 `pre` 记录前驱值；空位跳过；若当前值 ≤ `pre` 则非 BST。

```c
bool judgeBST(SqBiTree bt) {
    int pre = -1;                    // 结点值为正整数，-1 可作初值
    return inorder(bt, 0, &pre);
}
bool inorder(SqBiTree bt, int k, int *pre) {
    if (k >= bt.ElemNum || bt.SqBiTNode[k] == -1) return true;
    if (!inorder(bt, 2*k+1, pre)) return false;
    if (bt.SqBiTNode[k] <= *pre) return false;
    *pre = bt.SqBiTNode[k];
    return inorder(bt, 2*k+2, pre);
}
```

- 时间 O(ElemNum)，空间 O(树高)（递归栈）。
- T1 中序 `25,27,30,40,60,80` 严格递增 → **true**；T2 中序 `30,35,50,40,60`，`50>40` → **false**。
- 本地 Python 复算：`inorder_ok(T1,T2)=(True,False)`；源答案 2 的 `pmax/pmin` 代码复算同为 `(True,False)`。

**源原印疑点（两处，均不影响最终答案）**：

1. 源题 p5 在 T2 的存储结果后印“`T1.ElemNum = 11`”，按上下文应为 `T2.ElemNum = 11`。
2. 源答案 p7 写“以 `SqBiTNode[2i+2]` 为根的子树中的最小值（保存在 `pmin[2i+1]` 中）”。右子树根是 `2i+2`，其最小值应为 **`pmin[2i+2]`**；源页确实一致地印成 `pmin[2i+1]`，已用页图放大目视确认。**源页一致不等于数学语义正确**：独立推导与代码分支（`k%2==0` 用 `pmin[k]`）都表明正确下标是 `2i+2`。
3. 任务简报把该点写成“2022 Q42 的 pmin[2i+1]”；实际位于 **Q41 答案 2**（源答 p6–7），Q42 不涉及 pmin/pmax。

### Q42（10 分，最小 10 数）— `VERIFIED`

- 取前 10 个数建**大根堆**（堆顶为当前候选 10 个中的最大者）；顺序扫描其余 `n−10` 个数，每个与堆顶比较，更小则替换堆顶并向下调整；扫描结束堆中即最小 10 数。
- 平均时间 **O(n)**：每元素 1 次比较，期望替换次数 O(10·log n)，每次调整 O(log 10)=O(1)；空间 **O(1)**。
- 实测（Python，n=20000，随机数据 3 次）：大根堆比较次数 20342/20365/20361；10 元素有序数组插入解 20251/20250/20250。两者均约 n 量级。
- 源答案给出“10 元素有序数组”与“10 元素大根堆”两解，均 O(n)/O(1)；题目未指定唯一结构。

### Q43（15 分，数据通路）— `VERIFIED`

1. `SF = F15`。
   - 加法：`OF = ¬A15·¬B15·F15 + A15·B15·¬F15`
   - 减法：`OF = ¬A15·B15·F15 + A15·¬B15·¬F15`
   - （已按源答 p8 页图确认上划线。）
2. 单总线每一时刻只能有一个数据有效；`Y` 缓存 ALU 的一个输入，`Z` 缓存 ALU 输出，避免总线冲突与组合环路，保证运算稳定。
3. `rs`、`rd` 各 4 bit → 最多 `2^4 = 16` 个通用寄存器；二者来自**指令寄存器 IR**；`rd` 是写寄存器编号，接**地址译码器**；`rs` 是读寄存器编号，接**多路选择器**。
4. 取指控制信号：`PCout, MARin, Read, MDRout, IRin`；周期数 = 1（PCout/MARin）+ 5（Read）+ 1（MDRout/IRin）= **7**。
5. 控制信号由**控制部件 CU** 产生；连到 CU 输入端的是 **IR（操作码）与 FR（标志）**。

### Q44（8 分，磁盘）— `VERIFIED`

1. 地址信息三字段：**柱面号（磁道号）、磁头号（盘面号）、扇区号**。位数：20000 → **15** 位；4 双面盘片 = 8 面 → **3** 位；500 扇区 → **9** 位。
2. 7200 RPM → 8.333 ms/转；平均旋转延迟 4.167 ms；传输 1 扇区 8.333/500 = 0.0167 ms；平均访问 ≈ **9.18 ms**。
3. 缓冲区 64 bit = 8 B，512 B/8 B = **64 次**总线请求；CPU 同时访存时 **DMA 仍可获得总线**（周期挪用 DMA 优先级更高，且磁盘数据必须按时传送，否则缓冲区数据丢失）。

### Q45（7 分，文件系统）— `VERIFIED`

1. `stu` 目录项：`<course, 2>`、`<doc, 10>`（文件名 + 索引结点号）。
2. **x = 30**：图 b 中 `doc` 与 `course1` 的索引结点号同为 10（同一 inode，硬链接），`course1` 的数据块为 30，故 doc 也指向 30。

### Q46（8 分，信号量同步）— `VERIFIED`

跨线程的约束只有 **A→C** 与 **C→E**；B→C、C→D 在 T2 的程序序内，F 在 T1 内紧接 E，均无需信号量。最小解：

```c
Semaphore S_AC = 0;   // A 完成 → C 可执行
Semaphore S_CE = 0;   // C 完成 → E 可执行

T1:                    T2:
A;                     B;
signal(S_AC);          wait(S_AC);
wait(S_CE);            C;
E;                     signal(S_CE);
F;                     D;
```

说明：初次独立作答用了 4 个信号量（额外 `S_BC`、`S_CD`），逻辑上正确但冗余；按“T1/T2 之间”的同步关系最小化后应为上述 2 个。

### Q47（9 分，网络拓扑）— `SOURCE_ORIGINAL_ERROR`

1. 设备 1 = **100BaseT 以太网交换机**（隔离冲突域、不隔离广播域）；设备 2 = **100BaseT 集线器**（H2、H3 同冲突域）。
2. 争用期 = 64B/100Mbps = **5.12 μs**；信号往返各经设备 2 一次：`2×(1.51μs + D/(2×10^8)) ≤ 5.12μs` → **D ≤ 210 m**。
3. M 是 **DHCP 发现报文（DISCOVER）**；**E0 能收到**（同一广播域，交换机泛洪）；S 转发的目的 MAC 为 **FF-FF-FF-FF-FF-FF**。
4. H5 收到的 802.11 帧：地址 1 = `00-11-11-11-11-E1`（H5）、地址 2 = `00-11-11-11-11-C1`（AP）、地址 3 = `00-11-11-11-11-D1`（H4）。

**源原印疑点**：源答 p10 的代换式印成
`64B = (1.51μs + D/(2×10^8 m/s))×100Mbps`，
漏掉了上一行公式“最短帧长 = 总线传播时延×数据传输速率×**2**”中的 ×2。按原式会得约 722 m；补上 ×2 才得 **210 m**。最终答案 210 m 正确，属源页推导书写瑕疵，已页图目视确认。
