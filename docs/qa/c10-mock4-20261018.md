## 1. Q1：空间复杂度应为 A（`O(log2 n)`），源答案 B 错

题面（`paper p2`，定点渲染 `renders/paper-p02.png`）：
`fun(arr,m,n)` 在 `m==n` 返回 1，否则 `mid=(m+n)/2`，返回
`fun(arr,m,mid) + fun(arr,mid+1,n)`。

独立推导：两个递归调用是**顺序执行**的；左调用返回后其栈帧即弹出，右调用开始时左子树栈帧已不在。
任一时刻栈深 = 递归树高度 = `floor(log2 n)+1`，每帧 `O(1)`，故辅助空间 `O(log2 n)`。
实测（单线程脚本）：

| n | 最大栈帧数 | `floor(log2 n)+1` |
| --- | --- | --- |
| 8 | 4 | 4 |
| 1024 | 11 | 11 |
| 1048576 | 21 | 21 |

源解析（`sol p1`）写：“递归树…共有结点的数目是 `2^{log2 n}-1=n-1`，每个结点 O(1)，总空间 O(n)”。
这是把**递归树结点数**当成了**同时存活的栈帧数**；结点数只对应时间 `T(n)=2T(n/2)+1=O(n)`。
按**印出的“空间复杂度”**设问，正确答案是 **A**；`solutions.md` 的 B 与源解析均错。
**`SOURCE_ORIGINAL_ERROR`**。

> 另一种可能是底本把“时间”误印成“空间”：源解析给出的推导恰好是时间复杂度
> `T(n)=2T(n/2)+1=O(n)`。但本题按题面文字审：若问空间则 A，若问时间则 B；
> 现卷面写“空间复杂度”，故 B 仍不成立。是否属底本题面误印，留待第二复核。

> 顺带核对 Q1 的 C 代码形参与大括号：原生 JPEG 裁切 + 灰度窗拉伸（`renders/q1-w2.png`、
> `q1-tail1.png`）显示首行为 `int fun(int *arr, int m, int n)`，行末**没有**可辨的左花括号；
> `else {` 与末行 `}` 可见。`pages.yml` 的逐像素记录（`n` 后仅一处 2px 短竖）与本次直读一致。
> 因此 `questions.md` 的写法是对源卷的忠实转写，**不是转写漏字**；该片段作为标准 C 非法

## 3. Q42：源代码 `visit[cur]` 恒真，DFS 实际不递归

源解析（`sol p6`）代码：

```c
void dfs(Graph &G, int cur, int *visit) {
    visit[cur] = 1;
    for (int i = 0; i < G.n; ++i) {
        if (cur == i || visit[cur] == 1) continue;   // ← 应为 visit[i] == 1
        if (G.AdjGrid[cur][i] == 0) continue;
        dfs(G, i, visit);
    }
}
```

`visit[cur]` 在函数第一行已被置 1，故对每个 `i` 条件恒真，`continue` 总是执行，递归分支不可达。
`func()` 于是对每个未访问顶点只标记该顶点本身，返回值恒为 `n`。
最小反例：2 个顶点、一条边的连通图，正确连通分量数 1，该代码返回 2。
正确写法是 `visit[i] == 1`（注释“排除了自身、已访问、无路径”也表明原意是 `visit[i]`）。
**`SOURCE_ORIGINAL_ERROR`**（源解答代码错误；`solutions.md` 忠实转写）。
