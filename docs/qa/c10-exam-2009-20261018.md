## 6. 综合题推导（Q41–47）

### 6.1 Q41（10 分）— 贪心最近邻不能保证最短路径

结论：**不能**。

- **反例 1（贪心得到次优）**：顶点 1（起点）、2、3、4（终点）；边 `1-2=1`、`2-3=1`、`3-4=1`、`1-4=2`。从 1 选最近未访问点 2（距 1），再从 2 选 3，再从 3 选 4，路径 `1→2→3→4` 长度 3；而最短路径是 `1→4` 长度 2。局部最优导致全局次优。
- **反例 2（贪心无法到达）**：顶点 1（起点）、2、3（终点）；边 `1-2=1`、`1-3=2`。从 1 选最近的 2；到达 2 后没有未访问邻点，算法无法继续，**求不出 1→3 的路径**，尽管 1→3 存在。
- 排除“可行”：上述任一反例即否定“一定能求得最短路径”。源答案图 (1)/(2) 与这两个反例一致（已目视答案 PDF 第 7 页）。

### 6.2 Q42（15 分）— 单链表倒数第 k 个结点

**设计思想**：双指针一趟扫描。p、q 初始都指向第一个结点；p 先走，`count<k` 时只移动 p 并计数；`count==k` 后 q 与 p 同步后移；p 到 NULL 时，q 正好指向倒数第 k 个结点。

**步骤**：
1. `count=0`，`p=q=list->link`；
2. 若 p 为空转 5；
3. 若 `count==k`，`q=q->link`；否则 `count++`；
4. `p=p->link`，转 2；
5. 若 `count==k`，输出 `q->data` 并返回 1；否则返回 0（k 超过表长）。

**正确性/边界**：k=1、表长 3：q 最终指向第 3 个结点；k=2、表长 3：q 指向第 2 个；k=3、表长 3：q 不动，指向第 1 个；k>表长：count<k，返回 0；空表：p=q=NULL，返回 0。时间 O(n)，空间 O(1)。

**源代码核对**：答案 PDF 第 8 页印刷代码为 `int count=0; ... printf("%d",q->data); return 1;`；`solutions.md` 的代码块被 OCR 成 `countɰO`、`q--->data`、`%ct`（详见 §7-D7），但算法思想/步骤与印刷源一致。

### 6.3 Q43（8 分）— 中断与 DMA 的 CPU 占用率

已知：CPU 500MHz（`500×10^6` 周期/s），CPI=5；外设 0.5MB/s；每次中断传 32bit=4B；ISR 18 条指令 + 2 条指令其他开销。

**(1) 中断方式**
- 每次中断的时钟周期：`(18+2)×5=100` 周期。
- 每秒中断次数：`0.5MB/s ÷ 4B = 0.5×10^6/4 = 125000` 次/s。
- 每秒中断开销：`125000×100=12.5×10^6` 周期。
- 占 CPU：`12.5×10^6 / 500×10^6 = 2.5%`。

**(2) DMA 方式**
- 每次 DMA 传 5000B；5MB/s ⇒ `5×10^6/5000=1000` 次/s。
- 每次预处理+后处理 500 周期 ⇒ `1000×500=0.5×10^6` 周期/s。
- 占 CPU：`0.5×10^6 / 500×10^6 = 0.1%`。

单位说明：按十进制 MB（与源答案一致）；若按 MiB 会得到不同数值，但本题源答案采用十进制。

### 6.4 Q44（13 分）— `ADD (R1), R0` 执行阶段控制信号

指令功能：`(R0) + ((R1)) → (R1)`，即读 R1 指向的主存单元，与 R0 相加，结果写回该主存单元。

| 节拍 | 功能 | 有效控制信号 |
|---|---|---|
| C5 | `MAR ← (R1)` | `R1out, MARin` |
| C6 | `MDR ← M(MAR)` | `MemR, MDRinE` |
| C7 | `A ← (MDR)` | `MDRout, Ain` |
| C8 | `AC ← (A) + (R0)` | `R0out, Add, ACin` |
| C9 | `MDR ← (AC)` | `ACout, MDRin` |
| C10 | `M(MAR) ← (MDR)` | `MDRoutE, MemW` |

**等价优化**：C6 读内存的同时把 R0 打入 A（`MemR, MDRinE, R0out, Ain`），则 C7 可做 `AC ← (MDR)+(A)`（`MDRout, Add, ACin`），C8 `MDR←(AC)`，C9 `M(MAR)←(MDR)`，省 1 拍。两种方案均正确；源答案同时给出。

依据：`q44-fig.png` 数据通路（MAR/MDR/A/ALU/AC/R0/R1/PC/IR 及三态门/输入控制）与 `q44-fig2.png` 取指译码示例；`solutions.md` 的控制信号与图一致。

### 6.5 Q45（7 分）— 三进程奇偶缓冲区同步互斥

**信号量定义**：
- `mutex=1`：缓冲区互斥访问。
- `odd=0`：P1 已放入奇数的通知（P2 等待）。
- `even=0`：P1 已放入偶数的通知（P3 等待）。
- `empty=N`：缓冲区空单元数（P1 等待；P2/P3 取出后释放）。

**伪代码**：

```text
P1: while True:
      x = produce()
      P(empty); P(mutex)
      put(x)
      V(mutex)
      if x % 2 == 0: V(even) else: V(odd)

P2: while True:
      P(odd); P(mutex)
      getodd(); V(mutex); V(empty)
      countodd()

P3: while True:
      P(even); P(mutex)
      geteven(); V(mutex); V(empty)
      counteven()
```

**正确性**：P1 先等空位再互斥放入；P2/P3 先等对应奇偶信号再互斥取出，取出后释放空位。`odd/even` 保证消费者只取对应奇偶，`empty` 保证不溢出，`mutex` 保证缓冲区不被并发修改。无循环等待（每个进程最多同时持有一个资源信号量后申请 mutex），不会死锁。源答案语义一致；OCR 有 `mutex=l`、`mu七ex`、`mutext` 等字形错认（见 §7-D11）。

### 6.6 Q46（8 分）— 请求分页的访问时间与物理地址

页面 4KB ⇒ 页内位移 12 位。页表（`q46-fig.png` 目视）：页 0→帧 `101H` 有效；页 1→无效；页 2→帧 `254H` 有效。驻留集 2，LRU 局部淘汰；TLB 初始为空；TLB 未命中后访问页表（忽略页表后的 TLB 更新时间）。

**(1) 三次访问时间**
- `2362H`：页号 2，有效。TLB 未命中 `10ns` + 页表 `100ns` + 访存 `100ns` = **210ns**。
- `1565H`：页号 1，无效。TLB `10ns` + 页表 `100ns` + 缺页处理 `10^8 ns` + 重新 TLB `10ns` + 访存 `100ns` = **100000220ns**。
- `25A5H`：页号 2，第一次访问已把页 2 放入 TLB。TLB 命中 `10ns` + 访存 `100ns` = **110ns**。

**(2) 1565H 的物理地址**
- 访问 1565H 时页 1 缺页；驻留集已含页 0、页 2。LRU：页 2 刚在 2362H 访问，页 0 未被本序列访问 ⇒ 淘汰页 0。
- 页 0 的帧号 `101H` 分配给页 1；页内位移 `565H`（低 12 位）。
- 物理地址 = `101H << 12 | 565H = 101565H`。
