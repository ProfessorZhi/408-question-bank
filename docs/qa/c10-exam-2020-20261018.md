## 4. Q41–47 独立作答与核对

### Q41（13 分，三元组最小距离）— `SOURCE_ORIGINAL_ERROR`

**独立算法**：三个升序数组各设指针，每轮计算三点距离，记录最小值，然后推进当前最小值所在数组的指针；任一下标越界即停止。距离按三距离定义 `D=|a−b|+|b−c|+|c−a|`。

```c
int trip(int A[],int n,int B[],int m,int C[],int p){
    int i=0,j=0,k=0,best=INT_MAX,d;
    while(i<n && j<m && k<p && best>0){
        d = abs(A[i]-B[j]) + abs(B[j]-C[k]) + abs(C[k]-A[i]);
        if(d<best) best=d;
        if(A[i]<=B[j] && A[i]<=C[k]) i++;
        else if(B[j]<=A[i] && B[j]<=C[k]) j++;
        else k++;
    }
    return best;
}
```

- 示例暴力枚举：最小 `D=2`，三元组 `(9,10,9)`；三点法输出同为 `(2,(9,10,9))`。
- 时间复杂度 `O(|S1|+|S2|+|S3|)`，空间 `O(1)`；与源解析一致。

**源原印缺陷**：题 PDF p6 页图印的是 `D = |a−b| + |b−c|`（**只有两项**），并称“a,b,c **均为正数**”；而答案 PDF p9 页图明确写 `D = |a−b| + |b−c| + |c−a| = L1+L2+L3 = 2L3`，示例也含 `−1、−25`。`questions.md` 与源题 PDF 完全一致，因此**不是仓库转写错误**，而是源 PDF 的原印说明缺陷（漏第三项、误作“正数”）。最终算法与示例结果正确；是否修题干须等第二独立复核，本报告不改正文。

### Q42（10 分，前缀编码）— `VERIFIED`

### Q43（13 分，乘法实现）— `VERIFIED`

- （1）乘法可由加法+移位循环实现，编译器生成循环代码段。
- （2）控制逻辑控制加法/移位操作与循环次数。
- （3）①无乘法指令最长（软件循环多条指令）；③阵列乘法器最短（单周期）。
- （4）`x=2^31−1, y=2`，积 `2^32−2 = 0xFFFFFFFE`；64 位符号/无符号积均为 `0000 0000 FFFF FFFEH`。低 32 位作 `int` 为 `−2`，真值 4294967294 超出 int → `imul()` 溢出；作 `unsigned` 为 4294967294，未超 2^32−1 → `umul()` 不溢出。无符号取低 n 位时，高 n 位全 0 则不溢出，否则溢出。
- 独立脚本断言：积、低 32 位、unsigned 不溢出、signed 溢出，全部 PASS。

### Q44（10 分，Cache）— `VERIFIED`
