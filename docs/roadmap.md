## v1 剩余交付门槛

1. **构建层**：审核 Draft PR #24 的工具和 CI，确认 21 卷共 42 份实际构建文件，程序代码不被剥离、每张本地图有效、学生卷无显式答案泄漏、缺卷/缺题/缺解析使构建失败。
2. **来源层**：对已登记转录缺陷定点查源，并修复确有证据的错字、误挂图、乱码、公式、上标和代码残缺；不要用学术推理擅自改写原扫描文字。
3. **内容层**：原 PDF 自身可能印错的答案或算法，仅登记为来源疑点，补充备注，不作为改写 PDF 转录文本的理由。
4. **交付层**：完成相关 Draft PR 的 diff 与 CI 审核，再决定是否合并；通过 CI ≠ 获得合并授权。
