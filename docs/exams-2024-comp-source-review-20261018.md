## 3. 本轮修复的缺陷类型（逐题）

1. **广告水印串**：原稿在正文里混入了 `xlxj985211`、`微信：…`、`公众号：计算机考研数据`、`机考研数据`、
   `算机考研数据`、`185211`、`j9852`、`0211` 等十余种碎片，**七题全部存在**。
   已全部去除；`grep` 验证成品 `solutions.md` 中不再含任何水印串。
2. **乱码 / 形近误识**：
   - Q41 代码：`intuniquely(MGraphG)` → `int uniquely(MGraph G)`；`degree[］` → `degree[]`；
     `forillac` 一类丢失的循环头按原页恢复为 `for (j = 0; j < G.numVertices; j++)`；
     `prev_inoJEj` → `G.Edge[prev_in0][j]`；`>o)` → `> 0`；`return O` → `return 0`；
     `if(count=G.numVertices）` → `if (count == G.numVertices)`。
   - Q41 正文：原稿「将**的**所有邻接点」漏变量 → 「将 **$v$** 的所有邻接点」；
     「G.numVertices次则意味着」漏逗号 → 「`G.numVertices` 次，则意味着」。
   - Q44：「**7** 存放在 r2」→ 「**$i$** 存放在 r2」（数字 7 与斜体 i 的误识）；
     「sum 存放在 **rl**」→ 「**r1**」；「数组 **α** 至少存放在 2 页中」→ 「数组 **$a$**」。
   - Q47：「初始 TTL 值应该至少设置为 **160**」→ 「**16**」——
     这是原文句末句号「。」被误认成数字 0，属于**会改变数据的错误**，已按原页纠正。
3. **表格行列错位**：
   - Q42 的散列表原稿被压成一行无结构数字串（`1V2 0 3 4 5 6 … 18`）。
     已按原页还原为 **11 列**表：`[0]=11, [2]=14, [3]=7, [5]=20, [6]=9, [9]=3, [10]=18`，
     其余为空；7 项与 α=7/11 自洽。
   - Q46 的两张伪代码表原稿被拉平成竖列（`P1 / P2 / wait(S); / signal(S); / C2;` 混杂）。
     已按原页还原为 **P1｜P2 两列**表，并保留两条 `Semaphore …` 声明。
4. **公式上标丢失**：Q43「最多有 **2=32** 个通用寄存器」→ **$2^5=32$**；
   「log232=5 位」→ **$\log_2 32=5$**。
