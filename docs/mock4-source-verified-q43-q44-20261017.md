## 3. 算术旁证（自查，非 proofread）

**Q43 (4) 的机器码可被本轮的字段读数独立复算：**
按源页指令格式表，R 型 32 位 = `6位(000000) | rs | rt | rd | imm | op1`。代入源页解析给出的字段值

```
000000 | rs=00000 | rt=00010 | rd=00001 | imm=00010 | op1=010000
= 0x00020890
```

与源页写出的「**00020890H**」**一致**；且 `op1 = 010000` = 16 = **`10H`**，与题干
「逻辑左移的操作码为 10H」**一致**。两项互为旁证，说明本轮的字段读数与源页自洽 ——
但这仍是**转录后自查**，不是对源卷命题的独立验算（C10 人工闸门未做）。
