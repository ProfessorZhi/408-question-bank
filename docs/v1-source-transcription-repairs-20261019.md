## 四、结项门槛与边界

- v1 工程可用性由构建 PR #24 的 CI/单独组合验证确认；本分支的 QA 成功只是部分验收证据。
- 本分支不合并 \`main\`、不修改源 PDF、不重建覆盖索引、不把 \`needs-review\` 批量升级为 \`proofread\`。
- 本分支作为**来源转录修复候选**提交独立 Draft PR，供逐文件 review；真正完成 v1 还需维护者审核 PR、决定合并、最终审视保留的来源疑点。
- 本仓库目前 PUBLIC，但公开可见不意味着取得原试卷的再分发许可，相关权利风险独立见 \`RIGHTS.md\`。
