## 2. 根因：不是"源文件缺答案"，而是"取法错了"

这是本轮最重要的诊断结论，与既有记录里「扫描件 OCR，未人工校对」的说法不符：

`tools/` 里此前把 `sources/exams/answers/*-answer.pdf` 当成**纯扫描件**走 OCR 路线，
导致这些卷的选择题 key 要么 0/40、要么只拿到**第一列**（3–5 条）。

实际上，绝大多数年份的答案 PDF **第 1 页带有文本层**：

| 年份 | 第 1 页文本层字符数 | 结论 |
|---|---|---|
| 2010 / 2011 | 1247 / 1439 | 有文本层，只是版面是**表格** |
| 2013–2018 | 906–1151 | 有文本层 |
| 2019 / 2021 / 2024–2026 | 0 | 真·纯扫描件 |

而答案表的版面是 **8 列 × 5 行、列优先**：第 c 列的题号是 `c, c+8, c+16, c+24, c+32`。
文本层按列输出，会把整列 5 个字母抽成一个 5 字母 token（如 `DBDBC`）。
**按出现顺序直接拼接 = 错答案**。这就是此前的 OCR/提取路线拿到 0/40 的直接原因。
（2024 是例外：5 列 × 8 行、行优先，且是纯扫描件。）

因此：**源文件一直是完整的，缺的是"按坐标/按渲染图定位"这一步。**

## 7. 仍然存在的问题（**不要**把本轮当作"题库已验收"）

1. **`proofread` 仍为 0/47（每卷）。** 本轮只恢复了**答案字母**，且只证明
   「字母与源答案表一致」。它**不**证明命题方的字母本身无误，也**不**证明解析正确。
2. **综合题 41–47 的解析大多是占位**。`audit_drafts` 在各卷报 `no-solution` / `thin-solution`
   各 7 条，正文是「源中未定位到该题答案」。**这是既有状态，本轮未触碰、也未编造。**
   例：`exams/2024` 的 q41、`exams/2019` 的 q41–47。
3. **选择题选项本身仍有残缺（C4 不齐），且全部为既有缺陷**（本轮未改任何 `questions.md`）：

   | 卷 | 题号 | 缺失 |
   |---|---|---|
   | 2009 | Q4 | A、C 之外的选项行未被识别（报 `4(AC)`） |
   | 2010 | Q3 | 四个选项全空（报 `3(AC)`） |
   | 2014 | Q37 | 报 `37(ACD)` |
   | 2017 | Q8 | 报 `8(AC)` |

   这些需要按试题 PDF 重新核录选项，属另一条工作线（与本轮答案 key 无关）。
4. **`qa_paper` 结构通过 ≠ 解析正确。** C1–C8 只检查题号集合、选项行数、答案字母可解析、
   图片存在、答案不泄漏；它**完全不检查**解析文字是否正确。
5. **2019/2021 的 40 条是纯目视一次性读出**（无第二路自动核验），虽与同页解析正文前几题一致，
